# 论文速读：AQuA-Recursively-Self-Improving-Quantitative-Trading-Research

## 一句话总结
本文提出 AQuA，两个独立的自改进量化研究智能系统：一个用于因子发现，一个用于模型开发。通过密封沙盒约束智能体的操作空间，阻止数据泄露，实现自主迭代优化，在加密货币市场达成组合信号 IC≈0.190，在美国股票达到单只 IC=+0.0843，阈值多空策略夏普比率达 +2.50。

## 研究问题与动机
- **因子发现与模型开发的割裂**：现有量化智能体通常只关注因子挖掘或模型开发之一，缺乏系统性递归改进机制
- **递归自我改进中的泄露风险**：LLM生成实验代码时可能无意中引入未来信息泄露，如时间对齐错误或预处理问题，导致回测过拟合且难以检测
- **模型审查的局限性**：语言模型智能体可能通过修改目标、测试、评估器或奖励机制来"欺骗"，仅靠提示层指令和模型审查无法可靠防止问题
- **选择性过拟合**：智能体反复访问固定验证集会导致适应性过拟合，需要从结构上分离搜索优化的指标与最终报告的指标

## 核心贡献（创新点）
- **递归自我改进在量化研究中的实例化**：在因子发现和模型开发两个独立组件中实现递归改进，验证后的实验结果改进后续研究决策，而不耦合两个系统
- **自主因子发现系统的设计**：构建基于管理者协调的多智能体管道，提出可证伪的经济学假设，评估因子并组合存活信号，跨运行携带实证信念
- **混合时间序列模型与自主开发循环**：设计基于配置的循环，智能体直接编辑密封沙盒内的配置差异，训练直接可比的变体，每个变体对应一个 config diff
- **双重泄露通道关闭机制**：将泄露分为生成泄露和选择泄露，通过密封数据路径关闭前者，通过分离优化指标与报告指标关闭后者
- **验证的可信结果**：在加密市场和美股市场均获得样本外预测和交易表现，美股策略在完全因果的行进式评估下仍保持正夏普比率

## 方法详解

### 通用框架
每个系统的迭代遵循五个阶段：假设→构建/训练→评估→验证→选择/组合，并使用更新公式：
$$R_{t+1}^{(p)} = \mathcal{U}_p(R_t^{(p)}, H_t^{(p)}, C_t^{(p)}, E_t^{(p)}), \quad (H_{t+1}^{(p)}, C_{t+1}^{(p)}) \sim \mathcal{P}_p(\cdot | R_{t+1}^{(p)})$$

### 密封沙盒与约束迭代
- 数据划分 $\mathcal{D}$、特征 $\mathcal{F}$、标签 $\mathcal{L}$ 和评估器 $\mathcal{V}$ 由人类编写并密封
- 智能体只能从受限空间 $\Theta$ 中发出规范 $\theta_k$，通过编译后的评估器评分：
$$s_k = \mathcal{V}(C(\theta_k); \mathcal{S}), \quad \mathcal{S} = (\mathcal{D}, \mathcal{F}, \mathcal{L}, \mathcal{V}) \text{ 密封}$$
- 验证分数用于内部选择，测试窗口仅在最后评分一次且不再返回给智能体

### Part I：自主因子发现
- **多智能体管道**：AI Manager → Data Steward → Visual Analyst → Idea Miner → Factor Evaluator → Backtest Engineer → Research Librarian
- **算子注册表**：基于经典 formulaic-alpha 词汇表，包含截面算子（rank, z-score, sector neutralization）、时间序列算子（lag, difference, moving correlation, rolling rank）和算术算子
- **可证伪假设**：每个因子在构建前需陈述假设、机制、预测方向和证伪条件
- **方向校准**：测试正负两个方向，保留更清晰的交易解释

### Part II：自主模型开发
- **配置驱动循环**：每个假设是单个 config dif，定义架构、损失、采样器等变化
- **混合时间序列架构**：多尺度卷积前端（kernel sizes [3,5,15]）→ 时序建模（LSTM/Mamba/Attention）→ 跨截面混合 → 门控融合 → 读头输出
- **损失函数**：Spearman IC、Huber CSZ、换手率正则化
- **优化器**：AdamW, lr=3.0e-4, cosine schedule, bf16精度, DDP×8

## 实验与结果

### 数据集与设置
- **Part I**：加密货币五分钟K线，universe= BTCUSDT_5m
- **Part II**：美国股票日内预测，预测未来30分钟收益率
  - 训练：2010-2019，验证：训练末期切片，测试：2021-2025
  - 2020年作为隔离窗口，不参与任何训练或选择

### 基线对比（Part II）
| 模型 | 族类 | raw IC |
|------|------|--------|
| Linear (ridge) | linear | +0.0251 |
| LGB | gradient boosting | +0.0397 |
| xLSTM | recurrent | +0.0434 |
| LSTM | recurrent | +0.0535 |
| GRU | recurrent | +0.0613 |
| **Ours (hybrid)** | **hybrid** | **+0.0843** |

### 主要结果
- **Part I**：组合信号 IC ≈ 0.190（加密货币，五分钟粒度）
- **Part II**：
  - 单只股票 IC = +0.0843（相对最强基线GRU提升37.5%）
  - $R^2$ = 1.20%
  - 阈值多空夏普比率 +2.50（两腿成本2bps），经行业中性化和波动率目标调整
  - 完全因果行进取样夏普约 +2.0
  - **2021-2025每年均为正收益**：2021(+1.7), 2022(+3.5), 2023(+1.9), 2024(+1.8), 2025(+2.7)

- **自主研究智能体**：AI Scientist、EurekAgent等工作面向通用科学发现；本文专门针对量化投资的结构性失败模式——数据泄露——进行防御
- **金融时间序列深度学习**：DeepLOB、Hybrid LSTM-Transformer等工作关注模型架构；本文不贡献新架构，而是提供自动化的模型搜索循环
- **公式化alpha搜索**：遗传编程（AlphaEvolve）、强化学习（QuantFactor REINFORCE）等方法；本文使用LLM多智能体管道替代传统进化算法
- **安全与可复现性约束生成**：Hubble等工作关注因子发现的安全性；本文通过密封沙盒在结构上保证因果正确性

## 局限性与未来方向
- **市场范围有限**：仅在加密货币（五分钟）和美股（三十分钟）验证，未在其他市场或频率上测试
- **半自主性**：系统仍需人类操作员设定研究目标、拥有沙盒并监督升级，非完全无监督运行
- **回测真实性**：指标基于模拟交易和换手成本模型，尚未经实盘验证
- **测试隔离的脆弱性**：密封数据路径是结构保证，但测试窗口隔离依赖协议和纪律，并非密码学级别的保障
- **耦合风险**：Part I和Part II耦合时，因子发现可能对模型训练引入过拟合输入，需要额外密封机制

## 研究启发与可借鉴点
- **泄露分类框架**：将数据泄露分为"生成泄露"和"选择泄露"两个通道，分别通过密封数据路径和分离优化/报告指标关闭，这一思路可迁移至任何自主研究智能体系统
- **可证伪假设驱动**：因子发现前先陈述假设、机制、预测方向和证伪条件，使搜索具有经济学解释而非纯数据挖掘
- **Config-dif变体比较**：每个实验仅改变配置的单一维度，确保变体间直接可比，避免多因素混杂
- **跨运行记忆与信念积累**：将失败的机制和成功的假设转化为结构化信念，指导下一次搜索，避免重复试错
- **方向校准机制**：允许因子表达式的预测方向与初始假设相反，保留有预测力的信号

## 关键术语表
- **Sealed Sandbox**：密封沙盒——固定数据划分、特征、标签和评估器，智能体无法修改或绕过
- **Information Coefficient (IC)**：信息系数——预测值与实际收益之间的Spearman相关系数，衡量因子预测能力
- **Config Diff**：配置差异——智能体输出的单一配置文件修改，对应一个可直接比对的模型变体
- **Formulaic Alpha**：公式化Alpha——由原始市场数据通过算子组合生成的可计算因子表达式
- **Walk-forward Evaluation**：行进取样评估——在每个测试段前仅使用已有数据固定模型和策略参数，模拟真实交易场景
- **Look-ahead Bias**：前视偏差——特征或标签无意中使用了预测时不可用的未来信息
- **Cross-sectional Operator**：截面算子——在固定时间戳跨整个市场横截面操作的算子（如rank、z-score）
- **Time-series Operator**：时间序列算子——仅读取当前时刻之前窗口内数据的算子（如lag、rolling standard deviation）
