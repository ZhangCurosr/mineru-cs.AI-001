# 论文速读：Erase-but-Preserve-Controllable-Removal-of-Copyrighted-Animation-Characters-via-Optimized-Semantic-Anchors

## 一句话总结
本文提出了一种在文本到图像扩散模型**推理阶段**可控擦除受版权保护动画角色的方法，通过优化一个兼具"结构相似、细节不同"的连续语义锚点嵌入，并在去噪过程中自适应地替换目标相关嵌入，在彻底移除目标角色的同时保持图像整体保真度与背景一致性。

## 研究问题与动机
- **现有模型修改类方法**依赖选择"合适锚点"来替代目标概念，但对高度独特的动画角色（如蜘蛛侠、小黄人），其同义词或分类层级往往难以寻找或根本不可行；使用泛化锚点（如"ground"、空文本）会导致擦除不彻底与上下文污染。
- **现有 prompt-based 引导方法**（如 SLD、SAFREE、Negative Prompting）主要面向粗粒度 NSFW 内容过滤，缺乏对"擦除程度"和"保留上下文"的细粒度调控能力，无法区分"侵权视觉相似性"与"合法创作意图"的边界。
- **法律与平台治理现实需求**：不同法域/平台对动画角色侵权认定标准不一，往往允许"适度视觉相似"；平台更希望在保留构图、风格、背景等用户原创意图的前提下仅剔除受版权保护的角色本体，而非全量屏蔽。
- **基准缺失**：目前缺乏专门针对动画角色擦除的标准评测数据集与基准，限制了可比较的系统性研究。

## 核心贡献（创新点）
- **连续锚点嵌入优化框架**：将锚点构造为连续文本嵌入空间中的可学习向量，通过结构化轮廓约束（$\mathcal{L}_S$）与细节差异化约束（$\mathcal{L}_D$）联合优化，为高度独特的版权角色提供 principled 的锚点构造方案，区别于以往直接选取离散同义词或通用概念的做法。
- **结构感知自适应替换策略**：利用扩散去噪过程中低频结构信号的变化趋势自动判断嵌入替换的最优起始时刻（结构稳定后），避免在早期全局布局形成阶段介入造成的画面失真，本质区别在于"时序自适应"而非固定步数替换。
- **特殊嵌入融合机制**：借鉴语义可加性原理，将优化后的 EOT/Padding 嵌入以加权叠加方式融入原始特殊嵌入，显式处理目标相关语义残留，这一设计在已有工作中未被系统性利用。
- **细粒度可控擦除程度**：通过锚点与目标嵌入之间的向量插值 $e' = e_{anchor} + \alpha \cdot (e_{target} - e_{anchor}),\; \alpha \in [0,1]$ 实现擦除强度的连续调节，支持与多目标同步擦除及跨架构模型迁移（含 DiT-based 模型）。
- **即插即用锚点组件**：优化得到的锚点嵌入可直接作为良性替代概念接入现有模型修改基线（MACE、UCE、ESD-u、AC），在不动用任何额外微调的情况下提升其擦除准确率与图像保真度。

## 方法详解
- **整体流程**：首先从目标角色视觉语义中提取结构轮廓与细节特征以构建锚点概念（§3.1）；随后将该锚点优化为连续文本嵌入（§3.2）；推理时通过结构感知自适应策略在去噪过程中执行目标嵌入替换（§3.3）。
- **结构轮廓构造** $\mathcal{L}_S$：对随机高斯噪声 $x_T$ 采用确定性 DDIM skip-step 从较大 timestep $t_s \in (T_M, T_H)$ 处重建中间潜变量 $x_{t_s}$，再用目标 prompt $y_t$ 与锚点 prompt $y_a$ 分别重构 $\hat{x}_{0|t_s}(y_t)$ 与 $\hat{x}_{0|t_s}(y_a)$；经低通滤波 $f_L$ 提取低频分量后最小化二者 $L_2$ 距离（公式 9）。
- **细节差异化约束** $\mathcal{L}_D$：在随机 timestep $t_d \in (T_L, T_M)$ 向干净参考图 $x_0$ 添加噪声，最大化锚点 prompt 下噪声预测误差（公式 10），迫使锚点无法复原目标特有细节。
- **锚点嵌入优化**：初始化来自 CLIP 文本编码器中 token "Anchor*" 对应的 word vector $v^* \in \mathbb{R}^{1 \times D}$，在冻结 Transformer 层上构建包含 SOT/"Anchor*"/EOT/Padding 的 token 序列，反向传播仅更新 $v^*$，得到上下文化嵌入 $e^* = \{e^*_{SOT}, e^*_{anchor}, e^*_{EOT}, e^*_{Padding}\}$（公式 12）。
- **嵌入替换**：将输入 prompt 中与目标字符相关的 $n$ 个 token 嵌入替换为 $e^*_{anchor}$（公式 14）；同时将优化后的 EOT/Padding 嵌入按 $e'_{EOT} = \lambda_1 e_{EOT} + \lambda_2 e^*_{EOT}$ 融合（公式 15–16），最终生成替换后上下文嵌入 $e'$（公式 17）。
- **结构感知自适应触发**：每步去噪时对预测样本应用低通滤波得到 $f_L(x_t)$，计算相邻步低频结构 $L_2$ 变化量（公式 18）；当变化量由递增转为下降并达到阈值时自动启动嵌入替换，以避免破坏已稳定的全局布局。
- **细粒度控制**：通过 $\alpha$-插值 $e' = e_{anchor} + \alpha(e_{target} - e_{anchor})$ 在"完全擦除"（$\alpha=1$）与"不擦除"（$\alpha=0$）之间连续调节（公式 19）。

## 实验与结果
- **数据集**：自建 80 个动画角色数据集（36 个人形角色、23 个动物形态角色、21 个杂项角色），每个角色用 GPT-4o 生成 prompt，每角色采样 100 张图用于评估。
- **评估指标**：擦除有效性（LLaVA-1.5、BLIP-3 识别准确率，越低越好）；图像保真度（SSIM、LPIPS、Aesthetic Predictor V2 Score）；无关图像影响（COCO-30K 上的 FID 与 CLIP Score）。
- **最强结果（SD v1.4）**：LLaVA-1.5 识别率 **6.0%**、BLIP-3 识别率 **4.0%**，均优于次优基线（分别低 3.5% / 1.7%）；SSIM **0.467**、LPIPS **0.505**、Aesthetic **5.18** 均为最高/最优；FID 33.2、CLIP Score 0.312 与原始 SD v1.4（33.7 / 0.326）几乎一致。
- **跨模型迁移**：在 SD v1.5 / v2 / v2.1 / SDXL 以及 DiT-based Z-Image 上均有效，SDXL 达到 LLaVA-1.5 识别率 **5.6%**（Table 3）。
- **与模型修改方法结合**：将锚点嵌入替换进 UCE、ESD-u、AC、MACE 后普遍提升擦除效果（如 UCE 从 9.6% 降至 7.2%；ESD-u 从 36.0% 降至 13.6%），且不改变原有方法流程。
- **消融结论**：去掉结构约束使锚点优化失效；去掉细节约束导致锚点与目标过于相似；去掉自适应替换造成严重结构畸变；忽略特殊嵌入融合则擦除不彻底。

## 相关工作脉络
- **模型修改基线（MACE、UCE、ESD-u、AC）**：需修改模型权重，且依赖人工指定的锚点概念；本文锚点可与其无缝对接，解决其"锚点难以构造"的核心痛点。
- **Prompt-based 引导方法（SLD、SAFREE、TraSCE、Negative Prompting、STG）**：主要面向粗粒度 NSFW 安全过滤，缺乏对擦除程度与上下文保留的细粒度调控；本文针对动画角色的法律/平台治理诉求提供连续可控方案。
- **CLIP 文本编码器与语义嵌入空间研究（Brown et al., 2020；Zhuang et al., 2024）**：特殊嵌入（EOT、Padding）被证实编码布局与语义信息，本文在此基础上提出显式融合策略。
- **扩散模型去噪动力学分析（Kwon et al., 2022；Wang et al., 2024）**：前期关注低频结构、后期关注语义细节的先验被本文用于指导嵌入替换的最佳启动时机。
- **Flow Matching / DiT 基础模型（Lipman et al., 2022；Liu et al., 2023；Z-Image）**：验证了本文方法对 UNet 与 DiT 两种主流架构的跨架构泛化能力。
- **版权风险研究（Lu et al., 2024；Zhang et al., 2024）**：本文聚焦于"擦除而非屏蔽"的可部署路径，回应法律与平台治理中的现实需求。

## 局限性与未来方向
- **依赖预定义目标词列表**：嵌入替换需事先在"版权字符子空间"中标识目标 token，对未见角色或复合描述的泛化性未充分验证。
- **锚点优化计算开销**：每个角色需单独运行锚点嵌入优化（虽无需微调模型，但优化过程本身仍需若干步梯度下降）。
- **评估依赖 VLM 识别率**：以 LLaVA-1.5 / BLIP-3 识别准确率作为擦除有效性指标，可能受 VLM 自身偏差影响，尚缺针对版权相似性的专业评测协议。
- **复杂场景与多对象交互**：文中多目标擦除主要展示同图内多个独立角色，对于角色与背景强耦合、半透明遮挡等复杂情形未系统评估。
- **未来方向**：可探索自动化目标 token 检测、少样本/零样本新角色快速适配锚点、以及面向版权相似性的专用评测基准构建。

## 研究启发与可借鉴点
- **"结构-细节"双约束锚点构造范式**：将扩散先验（低频结构 vs 高频细节在不同 timestep 的主导性）转化为对比式损失，可迁移至其他"保留局部、剔除特定特征"的概念编辑任务。
- **时序自适应触发替换**：利用去噪过程中结构信号的单调性变化自动定位介入时机，避免人为设定固定步数，思路可推广至 prompt editing、inpainting 等需要精细控制的生成过程。
- **特殊嵌入融合机制**：对 EOT/Padding 等被视为"辅助"的嵌入显式利用，启示研究者重新审视文本编码器中各类 token 的语义分工，可在多语言、长文本、布局敏感场景中复用。
- **连续向量插值控制擦除强度**：$\alpha$-插值方案提供了一种无需额外调参的细粒度控制接口，可延伸至风格/属性编辑中的"编辑力度"调控。
- **即插即用锚点增强现有方法**：将推理时优化的锚点接入模型修改管线，为"无微调 + 微调"两类方案提供了统一评估视角，可作为后续工作的标准化组件。

## 关键术语表
- **Anchor Embedding（锚点嵌入）**：在连续文本嵌入空间中学习的、用于替代目标版权角色的 benign 概念向量，兼具目标的结构相似性与细节差异性。
- **Structure-aware Adaptive Replacement（结构感知自适应替换）**：根据去噪过程中低频结构变化趋势自动判定嵌入替换启动时刻的策略，以保护全局布局稳定性。
- **Diffusion Skip-step（扩散 skip-step）**：基于确定性 DDIM 调度器将多步去噪合并为单步跳变的加速采样技术，用于在较晚 timestep 处捕获全局结构。
- **LLaVA-1.5 / BLIP-3（识别评估模型）**：用于衡量擦除有效性的大规模视觉-语言模型，通过检测生成图像中目标角色的存在率评估擦除质量。
- **Classifier-free Guidance（CFG）**：扩散模型推理时常用的条件/无条件预测混合机制，多数 prompt-based 基线方法以此为基础进行引导。
- **FID / CLIP Score（无偏图像质量指标）**：分别在 COCO-30K 上计算 Fréchet Inception Distance 与 CLIP 匹配分数，用以评估方法对无关图像生成的负面影响。
- **Token Subspace（Token 子空间）**：预定义的与版权角色相关的目标 token 集合，用于在推理时定位需要被替换的嵌入位置。
- **DiT（Diffusion Transformer）**：以 Transformer 为去噪主干的扩散模型架构（如 Z-Image），本文验证了方法对其同样适用。
