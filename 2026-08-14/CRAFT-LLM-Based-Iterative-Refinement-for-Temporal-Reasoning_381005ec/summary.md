# 论文速读：CRAFT-LLM-Based-Iterative-Refinement-for-Temporal-Reasoning

## 一句话总结
论文提出 **CRAFT**（Clinical Refinement with Adaptive Feedback for Temporal ordering），一种基于生成器‑验证器迭代反馈的大语言模型框架，用于在锚点稀疏的临床自由文本中重建阶段式症状时间轨迹；同时发布专家标注基准 **MedTempo**（5,347 份新冠疫苗不良事件叙事，其中 3,166 份含时序证据），并在四种 LLM 上验证了该方法在时间排序准确性上的稳定提升。

## 研究问题与动机
- **核心问题**：从单份、时间锚点稀疏的临床自由叙事中重建结构化的阶段式症状时间轨迹。
- **现有方法不足**：
  1. 传统时间信息提取工作多聚焦于**成对关系分类**（pairwise relation classification）与局部关系正确性，而非端到端的有序轨迹重建。
  2. 临床领域已有工作普遍依赖**多就诊记录、带时间戳的监督信号或受约束数据设置**，难以处理单报告中隐式/相对时间表达。
  3. 当前临床时间推理基准多样性有限，缺乏针对**锚点稀疏单报告**场景的标准评测与标注数据。
  4. 自改进（Self-Refine 等）迭代范式在临床领域多依赖人工介入，不适合**跨模型层级**的系统化基准评测。

## 核心贡献（创新点）
1. **提出 CRAFT 生成器‑验证器迭代框架**：将时间轨迹重建建模为弱时间锚定下的迭代结构化预测任务，通过目标反馈持续修正候选时间线。
   - **本质区别**：不同于仅做单次生成或依赖成对关系组合的 pipeline，CRAFT 以任务特定的多准则验证器提供可操作的细化反馈，实现端到端的轨迹重构。
2. **引入 MedTempo 专家标注基准**：包含三种新冠疫苗类型的 5,347 份叙事，其中 3,166 份具有明确时序证据（MedTempo‑T）并提供阶段式排序标注。
   - **本质区别**：填补了单报告、锚点稀疏临床文本下结构化症状轨迹重建的评测空白，且分离出无时序进展报告（MedTempo‑NT）支持后续研究。
3. **系统评估四种 LLM 并揭示迭代行为差异**：CRAFT‑Full 在全部模型上均取得最高 EM，且迭代增益与模型能力密切相关。
   - **本质区别**：揭示了“高能力模型（如 GPT‑4.1）可从多轮反馈持续获益，而强基线（Claude）首 pass 已近饱和、弱模型（Llama/MedGemma）易过早收敛”的精细化规律。
4. **控制变量消融与对照基线**：定义 PIVOT（锚点验证器）、GUIDE（编辑条件生成器+锚点验证器）、CRAFT‑G（编辑生成器+加法验证器）、CRAFT w/o V（无验证器）以隔离各组件贡献。
   - **本质区别**：在统一设置下显式解耦生成器与验证器的独立效用，为迭代精炼范式的设计提供因果证据。

## 方法详解
- **任务形式化**：给定报告 $r$ 的自由文本 $x_r$ 与症状列表 $\mathcal{F}(r)=\{f_1,\dots,f_n\}$，预测有序时间桶序列 $B(r)=(B_1,B_2,\dots,B_K)$，每个症状恰好归属一个桶，桶内症状视为同时发生，桶间按时间先后排列。
- **迭代生成‑验证循环**（Algorithm 5.1）：
  1. **生成器（Generator Agent）**：在第 $i$ 轮接收症状列表、叙事文本与上一轮验证反馈（首轮为空），输出候选 JSON 时间线 $\hat{B}^{(i)}(r)$。CRAFT‑Full 采用**全量重新生成**策略，每轮均传入完整任务说明与反馈。
  2. **验证器（Verifier Agent）**：通过 **FormatTool** 规范化输出后，应用**加法评分规则**（0–5 分），每项 1 分：
     - JSON 合法且桶按最早→最晚排序；
     - 未提及症状在最后一组标记为 `"none"`；
     - 列表中每个症状恰好出现一次；
     - 同组症状在叙事中有明确同时发生的依据；
     - 组间顺序符合叙事中的时间线索。
  3. **决策与早停**：若得分 $\ge \theta$（默认 $\theta=3$）则接受并返回；否则将针对性反馈追加至上下文，进入下一轮，直至达到最大迭代数 $T_{\max}$（默认 4）后返回最后一个候选。
- **变体配置**：
  - **PIVOT**：全量生成器 + 锚点验证器（以接种日期为固定参考点，保守扣分）。
  - **GUIDE**：编辑条件生成器 + 锚点验证器（在上一候选基础上进行局部编辑）。
  - **CRAFT‑G**：编辑条件生成器 + 加法验证器。
  - **CRAFT w/o V**：仅单次生成，无验证反馈。

## 实验与结果
- **数据集**：MedTempo 共 5,347 份叙事（Pfizer/BioNTech、Moderna、Janssen 三种疫苗），其中 3,166 份含时序证据（MedTempo‑T）用于主要评测，2,181 份无时序进展（MedTempo‑NT）。症状中位数为 6，文本长度中位数 83–109 词。
- **基线模型**：GPT‑4.1、Claude Sonnet 4.5、MedGemma‑27B、Llama‑3.3‑70B。
- **评估指标**：严格精确匹配（EM）、Kendall’s $\tau_b$、Group‑Aware LCCS。
- **主要结果**：
  - **CRAFT‑Full 在全部四种模型上均取得最高 EM**（Table 5.1）：GPT‑4.1 35.61%、Claude 37.14%、Llama 28.04%、MedGemma 20.85%，均优于对应基线。
  - **相对于 PIVOT 的提升**：GPT‑4.1 +1.0、Llama +0.8、Claude +0.7、MedGemma +0.1；相对于 GUIDE 的提升更明显（GPT‑4.1 +1.6、Llama +2.0、Claude +1.5、MedGemma +0.7）。
  - **迭代增益与模型能力相关**：GPT‑4.1 从 i=1 到 i=4，EM 提升 8.7 个百分点（26.90→35.61）；Claude 首 pass 已近饱和（36.57→37.14，+0.6）；Llama 与 MedGemma 因验证器过早接受而收益有限。
  - **疫苗类型差异**：Moderna 叙事效果最好，Pfizer 最差（CRAFT‑Full 下 GPT‑4.1 差距 7.4 个百分点），该顺序在所有模型与设置下保持一致，表明数据集本身存在系统性难度梯度。
  - **消融结论**：移除验证器导致三模型 EM 显著下降（GPT‑4.1 −9.3、Llama −7.4、MedGemma −6.4）；将全量生成器替换为编辑条件生成器（CRAFT‑G）反而引入单调退化（GPT‑4.1 −3.8）。

## 相关工作脉络
1. **时间信息提取（TimeML、TempEval 系列）**：聚焦成对关系预测与全局排序诱导，侧重局部关系正确性，而非端到端轨迹重建。
2. **临床时间推理（i2b2 2012、THYME/Clinical TempEval）**：多依赖多就诊纵向记录或结构化时间元数据，难以直接应用于单份锚点稀疏叙事。
3. **Self‑Refine 等迭代精炼范式**：在原自然语言任务中通过自我反馈改进输出，但在临床领域引入人工 Review 循环，不适合自动化基准评测。
4. **临床时间关系抽取的 LLM 研究**：主要探索提示与微调用于关系抽取，仍需显式时间锚点或多时间戳监督。
5. **MedGemma 等医学专用 LLM**：在通用 LLM 基准上表现有限，本文显示其在锚点稀疏任务中差距进一步放大，凸显专用能力未必迁移至弱监督时序重构。

## 局限性与未来方向
- **验证器阈值固定**：$\theta=3$ 对部分模型（如 Claude）可能过于严苛，导致过早修正引入错误；需探索**自适应阈值校准**。
- **迭代效率**：最多 4 轮迭代平均消耗约 3 次调用，对弱模型增益有限；可研究**动态早停**或**预算分配策略**。
- **非时序报告利用**：MedTempo‑NT 的 2,181 份无时序进展报告尚未用于训练，未来可构建**时序证据识别模块**，实现“检测‑排序”一体化 pipeline。
- **疫苗域局限**：当前基准仅涵盖三种新冠疫苗不良事件，泛化至其他疾病领域或真实电子病历仍需验证。

## 研究启发与可借鉴点
1. **生成器‑验证器迭代范式可迁移**：将结构化预测分解为“生成‑校验‑反馈”闭环，适用于任意需满足多重约束的序列/分组任务（如医学事件排序、知识图谱补全）。
2. **任务特定验证器设计**：通过可解释的加法评分规则提供细粒度反馈，比纯 LLM 自我反思更稳定；可借鉴至其他需要约束满足的生成任务。
3. **迭代增益与模型能力的解耦分析**：本文通过消融揭示“高能力模型持续获益、强基线首 pass 饱和、弱模型过早收敛”的分层行为，为选择是否启用迭代精炼提供决策依据。
4. **评估指标的组合使用**：EM 衡量严格结构匹配，LCCS 奖励连续正确片段，$\tau_b$ 捕捉全局对数一致性；三者结合可全面刻画时序排序质量，避免单一指标偏差。
5. **疫苗不良反应叙事的结构化标注流程**：LLM 初标 + 双 annotator 独立审核 + 冲突调解的半自动化协议，可复用于其他需要专家验证的大规模医学文本标注。

## 关键术语表
- **CRAFT**：Clinical Refinement with Adaptive Feedback for Temporal ordering，一种基于生成器‑验证器迭代反馈的临床时间推理框架。
- **MedTempo**：Medical Temporal Ordering Benchmark，包含 5,347 份新冠疫苗不良事件叙事的专家标注基准。
- **Generator Agent**：CRAFT 中负责根据症状列表、叙事文本与反馈生成候选时间线 JSON 的大语言模型组件。
- **Verifier Agent**：基于加法评分规则（0–5 分）对候选时间线进行结构化校验并返回针对性反馈的组件。
- **EM（Exact Match）**：严格精确匹配指标，要求预测的阶段划分与桶内成分完全吻合。
- **LCCS（Longest Common Contiguous Subsequence）**：最长的连续公共阶段子序列，奖励相邻阶段完全正确。
- **$\tau_b$（Kendall’s tau‑b）**：处理并列关系的 Kendall 等级相关系数，衡量全局顺序一致性。
- **Anchor‑sparse narrative**：时间锚点稀疏的临床自由文本，仅含相对时间表达而缺乏绝对日期。

## 可复现要素
- **数据集**：MedTempo 已随论文发布（VAERS 数据经筛选与专家标注）；代码仓库见 https://github.com/LEAF-Lab-Stevens/TemporalAnalysis。
- **模型权重**：开放权重模型（Llama‑3.3‑70B、MedGemma‑27B）可通过 Hugging Face transformers 获取，使用 4‑bit NF4 量化；商业模型通过官方 API 访问。
- **关键超参数**：最大迭代数 $T_{\max}=4$，接受阈值 $\theta=3$，均通过 GPT‑4.1 在 100 样本开发集上网格搜索确定；解码采用确定性采样（无温度），`max_new_tokens=512`。
