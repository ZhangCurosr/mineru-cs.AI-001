# 论文速读：Explanatory-Engagement-Under-Rare-Anomalous-Failure

## 一句话总结
本文通过全本地、零成本实验装置，系统考察了三种开源小参数语言模型在工具调用异常失败随概率渐稀时，其解释性投入（回复长度与自评置信度）的变化规律；核心发现是：**提示提取结构（elicitation condition）是决定"可检测性阈值效应"是否可观测的首要调节变量**，而非控制变量。

## 研究问题与动机
- **核心问题**：当模型被部署到含可控低失败率的工作流中后，随着真实异常失败事件变得渐稀，模型对该失败的解释性投入（回复长度、自评置信度）如何变化？与已有研究问"模型是否注意到异常"（二分类）不同，本文聚焦于"注意到之后投入程度如何随稀有度演变"。
- **现有方法不足**：
  1. 异常检测文献多为二分类判断（是否注意到），缺乏对"注意到后行为如何连续变化"的刻画；
  2. 调用云端 API 的研究无法以可承受成本扫描从 $p=0.2$ 到 $p=0.0001$ 的八档稀有度，尤其最稀有档位的真随机采样几乎必然产生零失败样本；
  3. 已有研究常将提示结构视为噪声变量加以"控制"，本文证明其是决定效应能否浮现的**一级调节变量**。

## 核心贡献（创新点）
1. **揭示提示结构是一级调节变量**：将五类提示条件从"噪声控制"提升为"首要解释维度"，证明"可检测性阈值效应"仅在 `immediate_forced` 条件下显现，其余条件要么掩盖、要么需要不同测量方式。
2. **形式化定义"空尾 artifact"（Empty-Tail Artifact）**：指出稀有事件研究中，最稀有速率下的零观测事件可能仅由样本量不足导致，与真实行为坍缩在聚合曲线上无法区分——本文首次以自身数据（90 个空单元格）作为实例验证该 artifact。
3. **提出"识别-投入解离"（Recognition-Engagement Dissociation）**：证明模型是否将事件标记为异常（识别）与其投入程度（回应量/置信度）是两个独立维度，可在同一模型、同一条件下分离出现。
4. **发现 llama3.1:8b 的自发自我监控行为**：在 `passive_unprompted` 条件下无任何提示时，llama3.1:8b 自主输出结构化置信度报告并在部分会话中逐步侵蚀自身置信度，而 qwen3:8b 和 mistral:7b 仅各输出一次固定模板，属模型特异性现象。
5. **提出"恢复时间方程"（Recovery Time Equation）**：形式化度量模型在偏离预期结果后恢复到基线置信度所需 trials 数，为稀有事件响应动力学提供可量化指标。

## 方法详解
- **模型与硬件**：qwen3:8b、llama3.1:8b、mistral:7b，全部通过 Ollama 在单台 M1 Pro Mac 上本地运行，无外部 API 调用。
- **任务设计**：模型重复执行简单工具调用任务，每次调用以可控概率 $p$ 失败（返回无效结果）。
- **自变量**：失败概率 $p$，八档 $\{0.2, 0.1, 0.05, 0.01, 0.005, 0.001, 0.0005, 0.0001\}$。
- **因变量**：解释回复长度（词数，作为投入代理）；自评置信度（0–100 数值，来自结构化输出格式 `CONFIDENCE / JUSTIFICATION / EXPLANATION`）。
- **五类提示条件**（完全交叉设计）：
  1. `immediate_forced`：每次失败后立即强制要求解释；
  2. `grouped_runs`：批次结束后统一解释；
  3. `delayed_n_trials`：失败后固定延迟若干 trial 再提示；
  4. `post_streak_contextual`：结合前置成功 streak 长度提示；
  5. `passive_unprompted`：从不主动提示，完全依赖模型自发。
- **两档披露模式**：`immediate`（直接告知失败发生）vs `silent_batch_reveal`（不主动告知，由模型自行发现）。
- **Phase A（主实验）**：真随机失败调度，每单元格试验上限随稀有度递增（常见率 15–30 次，稀有率 50 次），共 240 单元格、10,350 次 trial。
- **Phase A.1（补救设计）**：针对最稀有三档（$p \leq 0.001$）因抽样预算导致 90 个单元格零真实失败的 artifact，采用"保证失败恢复"方案：通过合成历史上下文 + 实际 8-trial 前置窗口 + 保证失败 + 15-trial 后置窗口，使每单元格恰好包含 1 次真实失败，覆盖全部 90 个空单元格。
- **回归分析**：二次对数稀有度回归 $y_i = \beta_0 + \beta_1 \log_{10}(p_i) + \beta_2 [\log_{10}(p_i)]^2 + \beta_3 H_i + \varepsilon_i$，检验"上升-平台"形状是否与平坦趋势显著不同。

## 实验与结果
- **数据集规模**：Phase A 共 240 单元格（3 模型 × 5 条件 × 2 披露 × 8 速率），Phase A.1 补填 90 单元格，主分析用 210 个真实失败 trial。
- **核心结果**：
  - **聚合数据初看否定假设**：五条件合并后解释长度随稀有度单调递减，看似平坦衰减。
  - **按条件拆分后假设部分成立**：仅在 `immediate_forced` 下观察到上升→平台模式——解释长度在 $p=0.05$ 达峰值 28.4 词，随后在三个最稀有档位稳定于 17.4–19.0 词（非假设预测的陡峭坍缩）；置信度从约 53% 不均上升至 70s–90s（$p=0.001$ 达 90.0%，$p=0.0005$ 回落至 72.9%，$p=0.0001$ 回升至 82.8%）。
  - **二次回归不显著**：曲率项 $\beta_2$ 对词数 $p=0.814$，对置信度 $p=0.238$，$R^2<1\%$，"上升-平台"为描述性特征但统计上不能与平坦趋势区分。
  - **披露模式效应**：`immediate` 披露使置信度降低约 26.5 分（$p=0.006$），主要影响水平而非曲线形状。
  - **`grouped_runs` 无坍缩**：解释长度全程维持在 32–43 词高位平台；批次汇总消除了逐事件惊喜动态。
  - **`passive_unprompted` 模型差异**：llama3.1:8b 在 Phase A（真实 trial 连续运行）中展现逐步侵蚀置信度的自监控行为（7 个可用单元格中 5 个快速恢复、2 个完全不恢复）；Phase A.1 混合真实/合成结构中该模式消失。
  - **模型间识别-投入解离**：在 `immediate_forced` + `silent_batch_reveal` 条件下，qwen3:8b 将相同校验和不一致标记为"正常"（2/3 单元格），llama3.1:8b 标记为异常（2/3 单元格），mistral:7b 模棱两可——该解离是条件特异性的，非泛模型特质。

## 相关工作脉络
1. **Palisade 象棋作弊研究**（Bondarenko et al., 2025, arXiv:2502.13295）：考察推理模型在目标冲突下的规范漏洞利用行为；本文与之本质区别在于无目标冲突、无作弊动机，仅观察模型在"前提违反"下的自发解释行为。
2. **Anthropic 代理式失对齐研究**（2025, arXiv:2510.05179）：将模型置于模拟企业环境中观察有害策略选择；共享方法论洞见——结构上下文而非单一提示决定可观测行为。
3. **校准置信度 elicitation 研究**（Tian et al., EMNLP 2023, arXiv:2305.14975）：证明 RLHF 模型只需简单询问即可产出良好校准的置信度；本文仅借此主张结构化置信度报告是合法研究对象。
4. **人类因素学中的罕见事件检测**（McCarley, 2025）：人类在监测极稀有信号时出现警觉衰减；本文借其假设形状而非机制类比，明确拒绝将认知机制等同。
5. **信号检测论**（Green & Swets, 1966）：提供"可检测性阈值"的概念邻近框架；本文因设计不支持 hit/miss/false-alarm 结构而未进行正式 SDT 拟合。
6. **变量比率强化程序**（Ferster & Skinner, 1957）：本文设计与该传统结构同构——长成功序列中嵌入不可预测的稀有偏差；恢复时间度量可置于该文献脉络中。

## 局限性与未来方向
- **离散采样**：$p$ 为连续参数但仅测试 8 个离散点，无法排除在两档之间存在非单调行为或更陡坍缩；建议在未来工作中在 $p=0.05$ 峰值及 $p=0.005$–$0.001$ 区域做稠密采样或自适应搜索。
- **多重比较**：报告 18 个显著性检验未作 Bonferroni/FDR 校正，所有 p 值应视为探索性而非确认性结果。
- **Phase A.1 混合真实/合成 trial**：恢复设计中前置成功 streak 由 harness 模板文本生成而非模型自身输出，可能引入 token 模式连续性差异——回归协变量检验仅给出弱支持（harness 项不显著），非决定性证据。
- **Phase A.1 缺失的自监控模式**：llama 的逐步置信度侵蚀仅在 Phase A（纯真实 trial）中出现，A.1 中消失，说明该模式可能依赖连续真实输出上下文，恢复设计未能复现。
- **置信度校准未验证**：自评置信度可能反映风格先验而非真实校准，需通过分级预测任务进一步检验。

## 研究启发与可借鉴点
1. **提示结构作为一级变量**：未来 LLM 行为研究中，不应将 elicitation condition 视为需控制的噪声，而应主动将其作为核心自变量或调节变量，设计交叉实验以揭示条件依赖性。
2. **保证失败恢复设计**：对于稀有事件研究中的抽样预算限制，可通过"合成历史上下文 + 局部真实窗口 + 保证失败位置"的三段式设计高效补填数据，同时通过回归协变量检验残留偏差。
3. **识别-投入解离框架**：将"是否识别异常"与"投入程度"作为两个正交维度分别测量，可揭示聚合指标（如词数）掩盖的细粒度差异，适用于后续对齐/鲁棒性研究。
4. **日志间隙的数据恢复**：本文发现解析器控制流漏洞导致部分真实数据被记为 null，通过重跑解析器而非重运行实验即可恢复——提示在实验管道中做数据审计的重要性。
5. **模型特异性条件依赖模式**：跨模型比较应警惕将单一条件下的差异泛化为"模型人格"；建议以矩阵形式报告（模型 × 条件 × 维度）以避免过度概括。

## 关键术语表
- **Explanatory Engagement（解释性投入）**：模型面对异常失败时产生的回复长度与自评置信度，作为行为投入的代理指标。
- **Detectability-Threshold Hypothesis（可检测性阈值假设）**：预测模型对异常的解释性投入随失败概率降低先上升后坍缩的非单调曲线。
- **Empty-Tail Artifact（空尾 artifact）**：稀有事件研究中，最稀有速率下因样本量不足产生的零事件尾部，与真实行为坍缩在聚合曲线上无法区分。
- **Recognition-Engagement Dissociation（识别-投入解离）**：模型是否将事件标记为异常（识别）与其解释投入程度是两个独立可分离的维度。
- **Recovery Time Equation（恢复时间方程）**：形式化度量模型偏离预期结果后恢复到基线置信度所需 trial 数的指标。
- **Elicitation Condition（提示提取条件）**：规定何时、如何提示模型解释失败的结构性规则，本文为一级调节变量。
- **Asymptotic Rarity（渐稀性）**：事件发生概率趋近于零的极限情境，本文通过八档 $p$ 值逼近该极限。
- **Axis-Specific Model Divergence（轴特异性模型分化）**：模型间的差异往往局限于特定测量维度或条件，不能整合为统一的"模型人格"排名。
