# 论文速读：Capability-Sheaves-for-Compositional-Agent-Harness-Repair-Co

## 一句话总结
本文利用**层论（sheaf theory）**建模 AI agent harness 中各子系统的**局部一致但全局冲突**问题，提出基于**精确约束满足（CSP）**与**相对上同调类**的诊断与搜索框架，并在受控合成任务中验证了其不变性机制，但在真实 SWE-bench 补丁融合基准上未发现统计学显著优势。

## 研究问题与动机
- **局部有效但全局失配**：当前 agent harness 的各子系统（定位、契约、排序、保留、验证）各自可能“看起来”可行，但共享路径、版本、提交等状态无法粘合，导致无全局一致执行。
- **现有优化方法的不足**：现有工作通过外层搜索优化 prompt、程序或 agent 设计，仅用标量分数排名完整候选，无法解释和定位这类**局部到全局的执行失败**。
- **缺乏结构化诊断工具**：缺少一个统一的数学语言来分离**局部存在性**与**粘合条件**，并提供的可计算诊断信号以指导搜索。
- **真实仓库评估的差距**：在真实代码仓库的补丁融合任务中，如何严格评估结构性方法是否带来超越朴素语义证据的提升，仍不明确。

## 核心贡献（创新点）
1. **构建有限能力层**：为五个独立类型化需求（定位、契约、排序、保留、验证）构造了一个有限行为层，包含精确 CSP、相对类及独立检查的限制映射，本质区别在于将 agent 能力需求形式化为可执行的层结构而非黑盒评分。
2. **证明粘合与稳定性理论**：证明了精确粘合、局部得分分离、谱稳定性及有限迹修复恢复，同时给出线性松弛无效的反例，本质区别在于提供了严格的数学保证而非仅经验观察。
3. **受控隐藏状态实验**：设计了 20 个独立任务簇的受控实验，引入隐藏内部中介者，验证商空间消除干扰表示的不变性机制，本质区别在于通过因果干预分离了机制价值与泛化优势。
4. **真实仓库压力测试**：在 SWE-bench Multilingual 池的发现集（160 issues, 20 repos）上进行真实补丁融合测试，包含 875 候选补丁、2579 原子编辑及 153 新执行补丁，本质区别在于严格区分了机制验证与真实世界优势声称的边界。

## 方法详解
- **有限行为层构建**：定义 incidence 图 $X$，顶点为五个需求 $L,C,O,P,V$，边为六对重叠需求。每个顶点赋予**类型化行为签名茎**（如 localization 含 file path, namespace alias, symbol），每条边赋予**重叠茎**，限制映射 $\rho_{\nu\to e}$ 为**字面字段投影**（literal field projection）。
- **精确 CSP 可行性谓词**：候选 harness $c$ 被接受当且仅当所有局部谓词成立且所有注册重叠的限制一致：$\Phi(c) = \bigwedge_\nu [s_\nu(c)\in G_\nu] \land \bigwedge_e [\rho_{\nu\to e}s_\nu(c)=\rho_{w\to e}s_w(c)]$。这是** ordinary finite CSP**，层表述分离了局部存在性与粘合条件。
- **相对连接障碍与商空间**：将有限字段值用 $\mathbb{F}_2$ 上的 one-hot 基向量表示，定义胞腔上边缘算子 $\delta^0$，得到相对上同调类 $[\delta^0 s_A]\in H^1(X,A;\mathcal{F})$。当存在**隐藏中介顶点**时，商空间 $C^1(X,A;\mathcal{F})/\text{im}\delta^0_{\text{int}}$ 消除了内部表示噪声，类仅依赖端点分歧 $\ell_j+r_j$。
- **修复与搜索策略**：注册库包含五个变换（symbol-index router、revision ledger、workspace partition、dependency checkpoint、test-oracle verifier）。填充器改变类型证据并诱导局部截面。 outcome-blind completion operator 枚举候选池（25 个 bundle），按**相对障碍权重→精确提升比例→提名边际→填充器成本**的字典序最小化选择。
- **线性障碍的稳定性**：定理 4 证明秩截断残差稳定性：若估计矩阵 $\hat{D}$ 与真实 $D$ 的扰动 $\varepsilon<\gamma$（最小非零奇异值），则估计残差与真实残差的距离误差界为 $T=\tau+\rho B$，保证 lift/no-lift 决策的稳定性。
- **有限迹修复恢复**：定理 6 证明在弱面分数 $h(c)=\min_f\mu_{cf}$ 存在唯一最大值且间隙 $\Delta>0$ 时，通过 $n\geq\frac{8}{(\Delta-2\eta)^2}\log\frac{2Km}{\delta}$ 次新鲜迹观测，可概率恢复最优候选。

## 实验与结果
- **受控实验 1（基线搜索）**：200 个候选-块评估，71 个通过 heldout 测试（全部为精确联合成功）。完整相对类搜索比 adaptive NSGA-II 减少 **1.39 候选评估**（单侧 $p=0.0039$）；token 效率提升 DeepSeek 67.5%、GLM 71.6%。
- **受控实验 2（隐藏状态商）**：20 个独立任务簇×2 模型端点×25 候选 = 1000 个结果。**商策略**在每个 block 仅需 **1.000 候选评估**即可首次成功，而**陈旧原始策略**需 **2.000**（配对差异 +1.0，单侧符号检验 $p=2^{-20}=9.54\times10^{-7}$）。对齐内部状态消除差距，精确 CSP 与商匹配。
- **真实仓库压力测试**：
  - 数据：SWE-bench Multilingual 池的发现集，20 repos、160 issues、875 唯一源兼容补丁、2579 lossless edit atoms、153 新执行补丁。
  - **全池路由**：共同锚点解决 127 issues，匹配路由 109，相对路由 104，精确语义控制 96。相对 vs 匹配差异 −5/160，仓库宏观差异 −0.0316（$p=0.281$）。
  - **候选索引修复**：匹配选择器 116，受限商 118（+2 issues，但仅 3 repos 有效，$p=0.75$）。
  - **留一仓库 abstention**：商门控 127/160，匹配门控 126/160，仅 1 issue 差异（$p=1.0$）。
  - **开发门控未通过**：需至少 4 issue 增益、正仓库宏观效应、6 个非零 repos、$p\leq0.2$，均未满足，确认分割保持密封。

## 相关工作脉络
- **DSPy/AFlow/ADAS**：优化 prompt、程序、工作流或 agent 设计，使用任务目标与优化器状态作为结构权威，无声明的能力层；本文提供**可执行的层结构诊断通道**。
- **Meta-Harness**：设计可执行 harness 代码， proposer 可访问源、先前分数与迹；本文关注**固定候选池的结构化修复**而非端到端设计。
- **HarnessFix**：使用失败轨迹定位 harness 缺陷并验证范围修复，使用 ledger trace IR；本文使用**有限茎与精确 CSP**进行类型化粘合诊断。
- **PatchFusion**：确定性融合多个修复候选，报告 236/300 解决；本文使用**相同固定候选池但提问不同**：隐藏状态商是否在语义证据之外提供额外信息。
- **Olivieri & Hernández (2026)**：在 AI agent 基准中使用拓扑输运与粘合障碍排名科学理论转换；本文对象是**可执行的 agent 能力修复**而非理论转换。
- **神经层扩散与连接拉普拉斯网络**：学习图上的层值表示；本文对象是**可执行的能力抽象**，用于修复 agent harness 而非学习表示。

## 局限性与未来方向
- **受控实验的合成性**：任务使用生成 JSON、边界编辑语言和紧凑公开测试，目的为机制识别，**不估计自然仓库性能**。
- **隐藏状态干预的人为性**：陈旧中介者是故意干预，非部署系统实际包含陈旧状态的频率估计。
- **真实仓库评估的候选池固定**：仅测试一个固定候选池，七源 issue 分布与强锚点可能不代表其他生成系统。
- **原子边界有损**：虽然编辑原子无损，但义务与风险证据来自单次 GLM-5 传递，独立 GLM-5 与 Qwen 研究显示材料证据模型依赖性。
- **未来方向**：需要更强结构编码**实际跨编辑粘合的语义接口**，而非附加全局类到 issue；应在密封确认仓库打开前冻结新方法。

## 研究启发与可借鉴点
- **层论作为 agent 诊断工具**：将 agent harness 的子系统设计为层结构，利用**精确 CSP 与上同调类**提供可计算的粘合诊断，而非仅依赖标量分数。
- **受控因果干预验证机制**：通过引入隐藏中介者并比较商策略与陈旧原始策略，**严格分离机制价值与泛化优势**，为方法评估提供严谨范式。
- **开发/确认分割与门控协议**：在真实基准测试中预先注册开发门控标准（issue 增益、宏观效应、仓库多样性、$p$ 值阈值），未通过则保持确认分割密封，避免后选偏差。
- **有限迹恢复理论**：定理 6 提供采样复杂度界，指导**如何设计迹收集策略**以确保修复排序的一致性恢复。
- **稳定性分析框架**：定理 4 的秩截断残差稳定性分析为**从噪声迹估计结构约束**提供理论保障，可迁移至其他需要估计限制映射的场景。

## 关键术语表
- **能力层（Capability Sheaf）**：将 agent harness 的五个需求（定位、契约、排序、保留、验证）建模为 incidence 图上的有限层，茎编码类型化行为签名，限制映射为字段投影。
- **精确约束满足（Exact CSP）**：候选被接受当且仅当所有局部谓词成立且所有注册重叠的限制严格相等，作为语义决策规则。
- **相对上同调类（Relative Cohomology Class）**：由边界截面诱导的 $H^1(X,A;\mathcal{F})$ 中的类，零当且仅当相邻类型化限制一致，作为诊断与搜索特征。
- **商空间（Quotient Space）**：$C^1(X,A;\mathcal{F})/\text{im}\delta^0_{\text{int}}$，消除隐藏内部中介者表示的干扰，类仅依赖端点分歧。
- **填充器（Filler）**：改变类型证据并诱导局部截面的变换（如 symbol-to-file 检索、file-to-commit 溯源等）。
- ** outcome-blind completion**：按相对障碍权重、精确提升比例、提名边际、填充器成本的字典序最小化选择候选的策略。
- **秩截断残差稳定性（Rank-Truncated Residual Stability）**：估计矩阵与目标向量的扰动下，秩截断残差的误差界保证 lift/no-lift 决策的稳定性。
- **弱面分数（Weakest-Face Score）**：$h(c)=\min_f\mu_{cf}$，编码注册局部谓词或重叠同意事件的瓶颈分数。

## 可复现要素
- **数据集**：
  - 受控实验 1：200 个候选-块评估对（DeepSeek-V4-Flash 与 GLM-5-FP8 两个端点）
  - 受控实验 2：1,000 个隐藏状态元数据/结果对
  - 真实基准：SWE-bench Multilingual 池的发现集（20 repos, 160 issues, 875 候选补丁）
- **代码/权重**：配套 artifact 包含完整源代码（`src/capability_sheaves`）、配置、数据、结果、provenance 与测试；**无端点凭据**。
- **关键超参**：
  - 候选池大小：25 个 bundle（非空子集大小 ≤3）
  - 填充器成本：outcome-blind completion 在每任务副本中选择成本为 3 的 workspace partition + dependency checkpoint
  - 稳定性参数：$\varepsilon<\gamma$（最小非零奇异值），$\tau>0$，样本量公式 $n\geq\max\left\{\frac{2pq}{\varepsilon^2}\log\frac{4pq}{\delta},\frac{2p}{\tau^2}\log\frac{4p}{\delta}\right\}$
- **开源状态**：论文附录 A 提供可复现性清单，配套仓库包含所有元数据、结果与图示生成代码；真实仓库评估的开发协议在运行前固定。
