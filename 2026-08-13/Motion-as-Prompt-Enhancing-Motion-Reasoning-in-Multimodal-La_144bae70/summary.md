# 论文速读：Motion-as-Prompt-Enhancing-Motion-Reasoning-in-Multimodal-La

## 一句话总结
本文提出 Motion-as-Prompt (MaP)，一种无需训练、即插即用的跨帧视觉提示框架，通过从全帧率视频恢复密集点轨迹并在稀疏采样帧上显式标注轨迹段，使冻结 MLLM 直接感知对象位移、方向变化和动态交互，显著提升运动推理精度。

## 研究问题与动机
- **核心问题**：MLLM 处理视频时通常采用稀疏均匀采样以控制视觉 token 和注意力成本，导致帧间关键运动过渡（加速、转向、碰撞）完全丢失，形成"帧间运动损失"瓶颈。
- **现有方法不足**：
  - 运动感知视频模型（如 TimeChat、VTimeLLM、Seq2Time）需额外训练或修改模型架构，不可用于冻结 MLLM。
  - 现有像素级视觉提示（SoM、GoM）主要为帧内标注（对象区域、身份、空间关系），无法揭示跨帧运动证据。
  - 语义关键帧选择方法（AKS、FOCUS）可能保留描述"视频里有什么"的帧，却丢弃"对象如何运动"的证据。

## 核心贡献（创新点）
1. **识别输入侧瓶颈**：首次明确将"帧间运动损失"定义为稀疏采样 MLLM 的运动推理输入侧瓶颈，并提出跨帧运动恢复提示思路。
2. **MaP 框架**：提出 Motion-as-Prompt，结合运动引导采样与帧间轨迹标注，在不修改/训练 MLLM 的前提下恢复丢失运动信息。
3. **运动能量评估**：设计基于速度、加速度、曲率的三维度运动能量评分，用于自适应帧选择与轨迹渲染决策。
4. **通用性验证**：在合成场景 CLEVRER 和真实视频 SSv2 上均提升 GPT-5.5 表现，且在非运动推理任务 TempCompass 上不降级。

## 方法详解
MaP 包含三个核心模块：

**1. 运动信号提取**
- 使用冻结点追踪器 CoT racker3 在全帧率视频上追踪 $G \times G$ 查询点网格，定期重新初始化以覆盖新进入的对象。
- **相机运动补偿**：通过全局相似变换模型（平移 $b$、旋转 $R$、缩放 $s$）拟合所有可见点的位移，求解 $\pmb{\theta}^* = \arg\min_\pmb{\theta} \sum_{i \in \mathcal{V}_\ell} \|\mathbf{S}_\pmb{\theta}(\mathbf{p}_\ell^i) - \mathbf{p}_{\ell+1}^i\|^2$，得到对象速度 $\mathbf{v}_\ell^i = (\mathbf{p}_{\ell+1}^i - \mathbf{p}_\ell^i) - (\mathbf{S}_{\pmb{\theta}_\ell^*}(\mathbf{p}_\ell^i) - \mathbf{p}_\ell^i)$。
- **运动能量**：综合速度、加速度、曲率三维度，归一化后加权求和并平滑，得到 $M(\ell) \in [0, 1]$。

**2. 运动引导采样**
- 阶段一：均匀采样 $n_a = \max(2, \lceil \alpha B \rceil)$ 帧作为锚点（$\alpha = 1/4$），保证全局时间覆盖。
- 阶段二：剩余帧数通过带时间间隔约束（$r = \max(1, \lfloor N/2B \rfloor)$）的 NMS 在运动能量峰值处选取。
- 阶段三：若 NMS 不足 $B$ 帧，按运动能量降序填充。

**3. 帧间轨迹标注**
- 对每帧保留最大位移 $> \tau W$（$\tau = 0.03$）且总运动量前 $K$ 大的查询点。
- 在较晚采样帧 $s_k$ 上渲染累积轨迹段 $\gamma_k^i = (\mathbf{p}_\ell^i)_{\ell=s_{k-1}}^{s_k}$，以单色折线 + 末端圆点形式呈现，使 MLLM 可直接感知帧间运动。

## 实验与结果
- **数据集**：CLEVRER（合成运动推理，5 子任务：OE、MD、MC、MA、CI）、SSv2（真实视频细粒度动作识别）、TempCompass（非运动视频推理基线）。
- **模型**：Qwen3-VL-2B-Instruct（本地权重）、GPT-5.5（远程 API），均冻结。
- **主要结果**：
  - CLEVRER：GPT-5.5 + MaP 平均精度 79.1%（uniform 74.9%，提升 4.2%）；Qwen3-VL-2B 60.4%（57.6%，提升 2.8%）。
  - SSv2：GPT-5.5 + MaP 达 80.0%（uniform 71.1%，提升 8.9%）；Qwen3-VL-2B 53.2%（51.8%，提升 1.4%）。
  - TempCompass：MaP 在 4 个子任务上无降级（GPT-5.5 平均 88.6% vs 88.3%）。
- **消融**：轨迹标注贡献 +1.3%（GPT-5.5）/ +1.8%（Qwen3-VL-2B），运动引导采样贡献 +1.0%/+1.0%，标注是主要来源。
- **帧预算分析**：轨迹标注增益随帧数增加而增大（0.5→1→2 FPS），因密集观察提供更忠实轨迹。
- **预处理成本**：MaP 平均耗时 783ms（CLEVRER）、609ms（SSv2），GPU 内存 0.35GB，显著低于 SoM/GoM。

## 相关工作脉络
1. **关键帧采样**：AKS、FOCUS 基于语义相关性选择帧，但可能丢弃帧间运动证据；MaP 以运动能量为导向，保留动态过渡。
2. **视觉提示**：SoM 叠加对象分割掩码和编号，GoM 渲染场景图，均为帧内标注；MaP 补充跨帧轨迹维度。
3. **运动感知 MLLM**：VidEx pert、Flow4Agent、Dy nImg 等需修改模型或引入专用组件；MaP 完全训练自由、模型无关。
4. **时序定位方法**：TimeChat、VTimeLLM、Seq2Time 依赖显式时间感知训练；MaP 通过视觉标记直接提供时序运动线索。

## 局限性与未来方向
- **模型能力依赖**：MaP 的增益在强模型（GPT-5.5）上更显著，小模型（Qwen3-VL-2B）对轨迹标注的利用能力有限。
- **稀疏帧限制**：在极低帧率（0.5 FPS）下轨迹段退化为粗线段，且叠加标注可能遮挡原始视觉证据。
- **点追踪器局限**：CoT racker3 对快速运动、遮挡场景的追踪精度会影响能量评估和轨迹质量。
- **未来方向**：可扩展至多对象交互追踪、自适应 $\tau$ 和 $K$ 超参、结合时序提示（timestamp）的联合优化。

## 研究启发与可借鉴点
1. **输入侧补全思路**：对于任何因稀疏采样/压缩导致信息丢失的任务，可考虑在输入端显式恢复并标注缺失信息，而非修改模型。
2. **运动能量评估设计**：速度+加速度+曲率的三维度评估可用于其他视频分析任务（如事件检测、行为识别）的帧重要性评分。
3. **轨迹可视化提示**：折线+末端圆点的渲染方式简洁直观，可迁移至其他需要展示时序变化的视觉提示场景。
4. **低开销预处理**：MaP 仅 0.35GB 内存占用证明了运动恢复方法的计算可行性，为实时应用提供可能。

## 关键术语表
- **帧间运动损失（Inter-frame motion loss）**：稀疏均匀采样导致相邻采样帧之间对象运动证据完全丢失的现象。
- **运动能量（Motion energy）**：综合速度、加速度、曲率三个维度的标量评分，用于量化每帧的动态强度。
- **相机运动补偿（Camera-compensated velocity）**：通过全局相似变换估计并消除相机自运动影响，提取纯对象速度。
- **Set-of-Marks（SoM）**：通过在帧上叠加分割掩码和数字标识符实现视觉 grounding 的提示方法。
- **Graph-of-Mark（GoM）**：将对象及其空间关系编码为可见场景图的提示方法。
- **非极大值抑制（NMS）**：在运动引导采样中用于选择运动峰值帧的贪心算法，确保时间间隔约束。
