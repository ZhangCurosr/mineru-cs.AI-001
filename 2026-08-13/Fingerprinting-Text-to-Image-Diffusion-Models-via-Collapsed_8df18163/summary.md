# 论文速读：Fingerprinting-Text-to-Image-Diffusion-Models-via-Collapsed

## 一句话总结
本文提出一种**非侵入式模型指纹框架**，利用扩散模型中**坍塌生成（collapsed generation）**现象（特定输入条件下多次随机采样输出高度一致）作为模型内在行为签名，实现文本到图像扩散模型的知识产权验证，统一支持**白盒管道访问**与**黑盒 API 访问**两种场景。

## 研究问题与动机
- **知识产权纠纷激增**：专有 T2I 扩散模型常被以托管服务或可下载检查点形式分发，模型泄露、复制、未经授权微调引发的 IP 纠纷日益突出，亟需有效的保护机制。
- **现有非侵入式指纹方法存在局限**：基于内部表示/去噪轨迹的方法（如 FingerInv、DiffIP）需要检查点或可控生成管道，不适用于仅暴露为托管 API 的场景；基于查询的方法（如 TVN）多依赖优化的对抗提示词后缀，语言异常性易被检测为异常服务交互。
- **需要新型行为指纹信号**：期望一种证据体现为模型生成行为、在管道可控时可主动触发、仅在 API 输出可用时仍能通过自然提示词观察到的指纹信号。
- **坍塌生成的模型特异性**：坍塌生成是模型架构、训练数据、优化动态共同塑造的内禀属性，不同模型在相同提示下坍塌模式不同，可作为行为指纹基础。

## 核心贡献（创新点）
1. **将坍塌生成本质化为非侵入式指纹信号**：首次系统论证坍塌生成（跨种子一致性异常高）是模型内禀行为签名，可用于所有权验证，与水印方法无需嵌入额外信号的本质区别在于直接利用模型已有行为。
2. **统一白盒/黑盒验证框架**：通过同一坍塌生成签名桥接两种访问设置——白盒下优化连续嵌入（基于早期去噪截断优化），黑盒下挖掘自然提示词（基于训练低损失样本），避免现有方法分别依赖内部状态或异常后缀的局限。
3. **高效指纹构造与统计验证协议**：提出截断优化策略（仅优化前几步中间潜变量离散度）大幅降低白盒构造成本；设计基于正常生成参考样本的右尾 t 检验聚合多指纹响应，提供可复用的统计决策机制。
4. **在多种架构与混淆攻击下的鲁棒性验证**：在 UNet（SD 1.4/2.1、Deci）、Transformer（PixArt-α、SD 3）等模型上验证独特性，并在微调、剪枝、量化及自适应查询时混淆下保持有效，查询预算 modest（默认 M=4, K=4）。

## 方法详解
- **坍塌生成定义**：对提示词 p（对应条件嵌入 c），用 K 个独立初始噪声 x_T^(k) 生成图像 x_0^(k)，计算平均成对感知相似度 s̄_θ(c,K)；若超过阈值 τ_s 则视为坍塌。使用 SSCD（自监督复制检测）分数作为相似性度量。
- **白盒连续嵌入合成**：初始化 c_i = E_text(p_i)，采样 K 个噪声，通过**截断优化**最小化前 t_trunc 步去噪后中间潜变量离散度：L_Collapse = (1/K) Σ ||x_{T-t_trunc}^(k) - x̄_{T-t_trunc}||²₂。该观察基于早期去噪阶段坍塌倾向已确立，避免完整去噪的微分开销。重复 M 次得指纹集 C_f。
- **黑盒自然提示词挖掘**：利用坍塌样本集中在训练低损失区的规律，记录 per-sample 去噪损失，筛选低损失候选池 P_cand；在源模型上评估其交叉种子一致性，选顶部 M 个提示词构成 P_f。
- **统计验证协议**：对可疑模型 G_θ' 应用每个指纹条件，生成 K 个输出计算 s̄_θ'(f_m,K)，聚合得 s̄_f = (1/M)Σ s̄_θ'；构建正常生成参考（GPT-4 生成 N=50 个提示词的相似度分布 μ_0,σ_0），执行右尾预测 t 检验：t_f = (s̄_f - μ_0)/(σ_0√(1+1/N))，p_val = 1 - F_{t_{N-1}}(t_f)；若 p_val < τ_f（默认 10⁻⁴）则接受所有权主张。

## 实验与结果
- **数据集与模型**：控制实验用 CIFAR-10 独立训练的 4 个 DDPM；主实验使用 SD 1.4、SD 2.1、DeciDiffusion v1.0、PixArt-α、Stable Diffusion 3（UNet 与 DiT/flow-matching 架构）。
- **评估基线**：白盒 baseline FingerInv（基于 DDPM 反转 QR 码恢复）；黑盒 baseline TVN（非可转移对抗提示词后缀）。
- **独特性结果**：四 DDPM 控制实验中匹配对 p_val 显著低于不匹配对；T2I 模型交叉验证混淆矩阵呈明显对角分离，本方法区分度优于 TVN。
- **鲁棒性结果**：对剪枝（10%–30%）、量化（bf16/int8/fp4）、微调（SD 1.5/Deliberate v4/Realistic Vision v2.0）均保持 p_val 远低于阈值；黑盒下对自适应混淆（GPT 改写、RTA、EO、SAIL）亦稳健，p_val 最高仍为 2.33×10⁻⁶。
- **隐密性**：本方法自然提示词 perplexity（SD 1.4: 41.85, SD 2.1: 51.32）远低于 TVN（>200），更接近普通用户查询。
- **效率**：白盒优化每提示词约 25.03 秒，与 FingerInv（24.91 秒）相当，远低于 TVN（369.57 秒）；默认 M=4, K=4 仅需 16 次查询。
- **最强结果**：SD 1.4 黑盒验证 p_val 低至 8.63×10⁻²¹；所有混淆场景下本方法均成功，而 TVN 在多类攻击下出现误报或失败。

## 相关工作脉络
- **侵入式水印**（如 Zhao et al. [8]、Liu et al. [10]、Stable Signature [9]）：需训练时嵌入所有权信号，限制事后保护；本文方法无需修改模型，适用于已训练模型。
- **白盒非侵入式指纹**（FingerInv [13]、DiffIP [14]）：依赖内部表示或中间去噪状态；本文白盒验证仅需最终图像观察与嵌入注入，避免内部信息依赖。
- **黑盒查询指纹**（TVN [12]）：使用对抗后缀，语言异常易被检测；本文使用自然坍塌提示词，查询更隐蔽且通过统计检验增强可靠性。
- **坍塌生成/记忆研究**（Carlini et al. [15]、Somepalli et al. [17,27]）：关注训练数据提取；本文将其重新定义为模型内在行为签名用于所有权验证，视角不同。
- **模型特异性行为指纹**：本文证明独立训练实例（相同架构/数据/优化）因初始化差异产生可区分的坍塌模式，支持指纹唯一性要求。

## 局限性与未来方向
- **白盒嵌入难以离散化**：优化得到的连续嵌入无法直接映射为自然文本提示词（坍塌模式位于潜在空间狭窄区域，离散化破坏精确坐标），限制纯黑盒复用。
- **高度去重模型的自然坍塌稀疏**：如 SD 3 等采用严格数据去重的模型，自然坍塌提示词更稀少，虽可通过训练动态挖掘，但验证效果可能受影响。
- **黑盒查询预算与速率限制**：需收集 K 次独立生成，尽管预算 modest，但在严格速率限制的服务上可能仍需时间分摊。
- **未广泛评估商业大模型**：当前验证主要在开源模型（SD 系列、PixArt）上进行，对 Midjourney、DALL-E 等商业模型的适用性待探索。

## 研究启发与可借鉴点
- **截断优化策略**：利用早期去噪阶段已确立生成倾向，仅优化前几步中间潜变量离散度，大幅降低计算开销；可迁移至其他扩散模型属性优化或对抗样本生成任务。
- **训练动态关联低损失与异常行为**：通过监控 per-sample 训练损失高效挖掘具有特定行为（如坍塌、记忆）的样本；可用于模型可解释性分析或数据质量评估。
- **统一行为验证范式**：同一统计检验框架桥接不同访问设置，为多场景模型指纹设计提供可复用的统计决策模板。
- **自然提示词作为指纹载体**：避免对抗性修饰，提升黑盒验证的隐蔽性与实用性；可与现有提示工程方法结合。

## 关键术语表
- **Collapsed Generation（坍塌生成）**：特定输入条件下，多次独立随机采样产生高度一致图像的现象，反映模型内禀行为。
- **Cross-seed Consistency（交叉种子一致性）**：同一条件下多次生成图像的平均成对相似度，用于量化坍塌程度。
- **Fingerprinting（指纹识别）**：不修改模型参数，通过模型固有行为特征进行所有权验证的非侵入式方法。
- **White-box Verification（白盒验证）**：验证者拥有模型检查点与管道控制权，可注入连续条件的访问设置。
- **Black-box Verification（黑盒验证）**：验证者仅能通过 API 提交文本提示词并观察最终图像的访问设置。
- **SSCD Score（自监督复制检测分数）**：基于自监督模型提取图像表示后计算的余弦相似度，衡量视觉一致性。
- **Truncated Optimization（截断优化）**：仅优化前几步去噪过程以最小化中间潜变量离散度，避免完整采样微分的策略。
- **Adaptive Query-time Obfuscation（自适应查询时混淆）**：攻击者在验证查询期间应用的干预（如改写、添加令牌、优化嵌入/噪声），旨在破坏指纹一致性。

## 可复现要素
- **数据集**：控制实验使用 CIFAR-10；黑盒验证使用来自 [28] 的 500 个公共提示词集合（SD 1.4 与 SD 2.1）；白盒提示词部分来自 [28] 模板或 LLM 生成。
- **代码/权重**：预训练检查点从 Hugging Face 获取（如 CompVis/stable-diffusion-v1-4）；基线实现引用官方开源代码；**论文未声明本方法代码开源**。
- **关键超参**：白盒截断步数 t_trunc=5（SD 1.4/Deci）或 10（PixArt/SD 3），学习率 η=0.01 或 0.002，迭代次数 I=15–60；指纹集大小 M=4，每次生成数 K=4，验证阈值 τ_f=10⁻⁴；参考样本数 N=50；SSCD 使用 sscd_disc_large 模型。
