# 论文速读：The-Wording-Effect-Quantifying-Two-Way-Drift-in-LLM-Benchmar

## 一句话总结
本文提出 BenchDrift 框架，通过生成意义保持的表述变体并严格验证答案不变，量化 LLM 在基准测试中正负双向漂移率，揭示单点得分背后平均高达 74.7 个百分点的能力区间；强模型的高分往往因表述敏感而虚高，弱模型反而能从重述中获益。

## 研究问题与动机
1. **单表述得分的稳定性缺失**：现有基准仅用单一问法评估模型，未覆盖同一问题在语言、结构、语境等维度上的合理变体空间，导致得分无法反映模型的真实能力边界。
2. **现有方法的归因缺陷**：传统鲁棒性/对抗测试常改变问题内容或正确答案，无法区分“能力不足”与“表述敏感”；Prompt 优化器（如 DSPy、GEPA）采用搜索-丢弃策略，仅保留最优提示，丢失了变体分布的全貌信息。
3. **强弱模型漂移方向的系统性差异**：直觉上认为重述应普遍提升表现，但本文发现漂移具有方向不对称性——强模型负漂移显著高于正漂移，弱模型则相反，这一规律尚未被量化研究。
4. **可靠性验证的缺失**：已有研究多依赖单一 LLM 评委或人工标注，缺乏对测量流水线（生成器/验证器/裁判）角色互换的系统性检验，难以排除工具伪影。

## 核心贡献（创新点）
1. **提出 BenchDrift 双向漂移量化框架**。通过四轴变体生成与答案守恒验证，将单点准确率扩展为 Worst/Rep./Best 区间，且每个翻转均严格归因于具体变换。区别于前人仅报告“输出变化”的工作，本文强制正确答案不变，确保漂移完全由表述驱动。
2. **定义共享分母的正负漂移速率公式**。`Pos` 与 `Neg` 均以原始问题集大小 N 为分母，使两种方向的敏感性具有直接可比性。区别于单方向鲁棒性度量，该设计同时捕捉“隐藏能力浮现”与“表面鲁棒性暴露脆弱”。
3. **多角色交叉验证证明漂移的模型属性**。通过独立替换 Generator、Validator、Judge 的 LLM 组合，证明漂移排名高度稳定（Spearman ρ ≥ 0.98），且无单一角色主导测量结果。区别于多数依赖固定评测器的研究，本文排除了流水线配置带来的系统性偏差。
4. **开源完整管道与验证变体数据集**。公开 BenchDrift 代码、变体分类法及实验中生成的全部通过验证的变体。区别于仅开源部分代码或提示词的工作，本文提供可直接复现的双向漂移基准资源。

## 方法详解
- **四角色流水线**：`Generator` 提议变体 → `Validator` 验证变体答案与原 Ground Truth 一致（仅允许等价表述改写，禁止数字/单位/逻辑条件变更）→ `Target model` 回答原问题及所有合法变体 → `Judge` 评分（接受同义数值表达如 "12"/"twelve"/"a dozen"）。
- **双向漂移定义**：设问题集为 $q$，Ground Truth 为 $a$，合法变体集为 $V(q)$，正确性判定函数为 $C(q) \in \{0,1\}$。则：
  - **正漂移**：$C(q)=0$ 且 $\exists q'\in V(q), C(q')=1$（原表述掩盖能力）
  - **负漂移**：$C(q)=1$ 且 $\exists q'\in V(q), C(q')=0$（原表述虚增鲁棒性）
  - 速率公式：$\text{Pos.} = \frac{1}{N}|\{q:C(q)=0,\exists q',C(q')=1\}|$，$\text{Neg.} = \frac{1}{N}|\{q:C(q)=1,\exists q',C(q')=0\}|$
  - 区间关系：$\text{Best} = \text{Rep.} + \text{Pos.}$，$\text{Worst} = \text{Rep.} - \text{Neg.}$
- **四轴变体分类法**：`Linguistic`（措辞/语态/礼貌/符号化等）、`Referential`（实体替换/单位换算等）、`Pragmatic`（人设/框架/直接提问等）、`Structural`（句子重组/段落顺序/空白/引号等），共涵盖 32 种具体变换。
- **自适应变换选择**：先扫描问题文本提取 20 项属性（数字、单位、实体、分段等），按匹配度排序四轴，再按 1.0 : 0.75 : 0.55 : 0.40 的比例分配变体预算，确保高匹配轴获得更多采样。
- **验证机制**：Validator 仅回答一个问题：“若读者从未见过原题，仅凭此变体能否得出相同答案？”通过则保留，否则丢弃，确保后续漂移完全由表述驱动。

## 实验与结果
- **数据集**：GSM8K、MMLU、MATH-Hard，各采样 500 题，涵盖数学推理与事实问答。
- **模型**：8 个开源模型（7B–34B），包括 GPT-OSS-20B、Phi-4、Qwen2.5-7B、Granite-3.3-8B、Llama-3.1-8B、Qwen3-8B、Granite-34B-Code、Mistral-7B。
- **主配置**：Mistral-Large-Instruct-2411 生成，GPT-OSS-120B 验证，Llama-3.3-70B-Instruct 裁判；目标模型采用 CoT 提示、temperature=0。
- **核心发现**：
  - 平均 Worst-Best 区间跨度达 **74.7 个百分点**（GSM8K 上 Phi-4 从 93.4% 报告分跌至 38.2% 最坏/升至 99.2% 最好）。
  - 正负漂移不对称性与基线准确率高度线性相关（Pearson $r=0.98$，斜率 1.08）：基线 >60% 时负漂移全面占优；<60% 时两者均衡或正漂移略多。
  - 漂移集中分布于特定变换：`interrogative expansion` 造成最高负漂移（48.9%），`whitespace add` 最低（11.7%）；跨模型对高代价变换的排序高度一致（Spearman $\rho=0.77$）。
  - 模型自身置信度无法预测脆弱性：高置信（≥0.95）题项仍面临 13%–26% 的负漂移率。
  - 采样效率：平均 20.2 个变体/题；仅 5 个变体即可覆盖 74% 的漂移问题，10 个覆盖 93%。
  - 对比 Prompt 优化器：在相近耗时下，BenchDrift 输出完整区间（如 Llama-3.1-8B 在 15 题上为 26.7%–86.7%–100%），而 DSPy/GEPA 仅返回单点得分。

## 相关工作脉络
1. **与标准基准评测（GSM8K/MMLU/MATH-Hard）相比**：仅报告单次 pass@1 得分；本文将其扩展为含 Worst/Rep./Best 的稳定性区间。
2. **与对抗/行为测试方法（CheckList, Robustness Gym）相比**：通过修改任务实质诱导失败，答案变化无法归因于表述；本文严格保持答案守恒，实现纯表述敏感性的因果隔离。
3. **与 Prompt 优化器（DSPy, GEPA, AutoPrompt）相比**：采用“搜索-丢弃”保留最优提示；本文保留全部合法变体并逐条归因，提供能力分布全景。
4. **与格式/同义鲁棒性研究（Sclar et al., 2024; Elazar et al., 2021）相比**：仅统计输出变化比例；本文建立正/负漂移双指标体系，并与具体变换轴、置信度分箱、问题长度绑定分析。
5. **与推理时聚合方法（Self-Consistency, LLM-Blender）相比**：以 5–40× 计算代价压制方差，仍输出单点分数；本文以更低开销直接刻画变体覆盖的能力边界。

## 局限性与未来方向
- Judge/Validator 均为 LLM，未进行人工标注校准，可能存在共享盲点或方向性容忍偏差。
- 仅评估封闭式答案基准，开放生成任务（摘要、长文写作）的漂移行为尚未可知。
- 生成/裁判模型与目标模型同属 Mistral/Qwen 家族，可能存在家族级偏差残留。
- 轴级归类由变换标识符映射推断，不同分组方式可能影响轴级统计。
- 端到端成本高于单次评估，目前更适合周期性审计而非常态化评测。
- 未来方向：引入人类验证校准漂移阈值；扩展至开放生成任务；探索低负漂移提示模板的自动搜索；结合训练数据分布分析漂移根源。

## 研究启发与可借鉴点
1. **可复用的两阶段验证流水线**：Generator-Validator 解耦设计（生成多样性+答案守恒过滤）可直接迁移至其他模态或任务领域的鲁棒性审计。
2. **共享分母的双向速率设计**：Pos/Neg 使用相同分母 N 的公式使不同模型/基准的敏感性具备直接可比性，Best/Worst 可由 Rep/Pos/Neg 精确反推，适合纳入标准化评测协议。
