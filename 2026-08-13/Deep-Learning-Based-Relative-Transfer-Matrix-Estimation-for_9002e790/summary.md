# 论文速读：Deep-Learning-Based-Relative-Transfer-Matrix-Estimation-for-Multiple-Sources-and-Multiple-Microphones

## 一句话总结
本文首次将深度学习引入相对传递矩阵（ReTM）的盲估计任务，提出三种基于时域与STFT域的端到端网络框架，在多声源多麦克风仿真场景下显著提升了ReTM估计精度，并在语音去噪下游任务中验证了其优于传统协方差基线的实用价值。

## 研究问题与动机
- 传统相对传递函数（ReTF）估计依赖W-离散正交性假设，无法处理房间中同时激活的多个声源。
- ReTM作为ReTF的矩阵推广，此前唯一可行的盲估计方法仅依赖麦克风信号协方差矩阵，在非均匀频谱噪声与强混响条件下精度受限。
- 机器学习在单声源ReTF估计中已展现优势，但针对多声源ReTM的表征学习与空间映射建模尚未被探索。
- 实际音频应用（机器人听觉、助听器、视频会议）亟需高精度、可端到端训练的ReTM估计模块以支撑后续波束成形与声源分离。

## 核心贡献（创新点）
1. 提出SCoNet、FuSNet和LAeNet三种监督学习框架，分别利用STFT域深度可分离卷积、时域可学习1D卷积滤波器组以及共享BiLSTM自编码器完成ReTM的空间映射建模。
2. 设计跨时频联合损失函数（负SDR + RSE），强制模型同时优化时域波形保真度与频域谱结构，提升对噪声与伪影的鲁棒性。
3. 在四种仿真房间配置下系统验证，证明DL方法在多数定量指标上显著优于协方差基线，并在语音去噪任务中实现平均+10.55 dB SDR提升。
4. 完整剖析三种架构的参数规模、推理延迟与显存特性，为不同实时性要求的音频前端提供可复用的选型参考。

## 方法详解
- **信号模型**：将Q个麦克风划分为两组A（$Q_A$个）与B（$Q_B$个），ReTM定义为 $\mathcal{R}_{AB}(f) = \mathbf{H}_A(f)\mathbf{H}_B(f)^\dagger$，目标是学习映射 $M_A = F_B(M_B)$（STFT域）或 $m_A = f_B(m_B)$（时域）。
- **SCoNet**：输入 $M_B(f,t)$，将实部与虚部堆叠至通道维，在时频轴执行二维深度卷积，使每个频率bin独立学习一组空间传递系数，输出重组为 $M_A(f,t)$。
- **FuSNet**：纯时域架构，使用 $Q_A \times Q_B$ 个1D卷积核直接参数化冲激响应 $r_{AB}^{ji}(t)$。输入长度为L的非重叠语音段及其前后各L的上下文窗口（总长3L），卷积求和后对齐原长度输出 $m_A(t)$。窗口长度需大于房间混响时间（$T_{60}$）以满足乘性传递函数近似。
- **LAeNet**：频域自编码器，每个频率bin的拼接序列通过共享权重的BiLSTM提取时序上下文，经层归一化后沿时间维度平均得到固定长度特征向量，再由全连接层 $k(\cdot)$ 预测ReTM系数，最终按矩阵乘法重构 $M_A$。
- **训练策略**：损失函数 $L = -\alpha L_{SDR} + \beta L_{RSE}$，其中 $\alpha=1, \beta=10$。采用Adam优化器，学习率根据验证集性能自适应衰减，联合优化兼顾时频一致性。

## 实验与结果
- **实验设置**：仿真6×7×3 m矩形房间（$T_{60}=500$ ms），使用开源RIR工具箱生成脉冲响应。麦克风配置：场景A1/A2/B为 $Q=7$（$Q_A=3, Q_B=4$），场景C为 $Q=12$（$Q_A=5, Q_B=7$）。所有麦道叠加40 dB白噪声并下采样至16 kHz。
- **评估基线**：协方差矩阵法（ReTM baseline [10]）。
- **核心指标**：SDR、MSE、LSD、APD、RSE。
- **主要结果**：
  - **A1（双白噪声）**：FuSNet全面领先（SDR 29.13 dB，MSE -59.25 dB），均匀频谱利于时域卷积收敛。
  - **A2（双非均匀噪声）**：FuSNet在LSD/APD上出现明显退化；SCoNet与LAeNet保持与基线相当或更优的水平。
  - **B/C（含语音+多噪声源）**：麦克风数量增加显著提升所有方法精度；SCoNet在B场景MSE最优，FuSNet在C场景整体最优。
  - **语音去噪应用**：LAeNet表现最佳（B场景SDR +8.67 dB/STOI 0.92，C场景SDR +7.03 dB/STOI 0.91），较基线平均提升+10.55 dB SDR与37% STOI；FuSNet因残留回声导致去噪性能下降。
  - **计算效率**：FuSNet参数最少（98.3k）且延迟最低（1.07 ms）；LAeNet延迟最高（1.80 s）但显存随窗口长度增长保持恒定。

## 相关工作脉络
- **协方差ReTM估计 [10]**：本文直接对比基线，依赖二阶统计量求解Moore-Penrose逆，缺乏对非平稳复杂噪声的适应性；本文用数据驱动映射替代解析求解。
- **单声源ReTF深度学习估计 [23]等**：聚焦标量传递函数学习；本文将其推广至多声源矩阵形式，引入空间交叉组映射与联合时频损失。
- **多通道维纳滤波/广义特征值波束成形 [11]-[17]**：传统空域滤波需精确ReTF/ReTM先验；本文提供端到端估计替代方案，可直接嵌入现有处理链路。
- **ReTM语音增强应用 [27]**：本文复用其降噪验证框架，首次证明DL估计的ReTM可超越协方差先验并带动下游指标提升。
- **多线索多通道增强网络 [32]**：SCoNet借鉴深度可分离卷积的通道独立学习思想，但将其专注应用于空间传递矩阵建模而非频谱掩蔽。

## 局限性与未来方向
- 假设声源与房间脉冲响应完全静止，未考虑移动声源或动态混响变化。
- FuSNet在非均匀频谱干扰（如空调/音乐）下LSD/APD显著恶化，时域卷积对频谱形状过于敏感。
- 语音去噪中时域模型（FuSNet）残留明显回声，缺乏联合去混响能力。
- LAeNet训练延迟较高（约1.8 s），难以直接部署于超低延迟实时前端。
- 未来将拓展至声源分离、联合去混响，并系统探索最优麦克风分组与布局策略。

## 研究启发与可借鉴点
1. **时频联合损失设计**：$L_{SDR} + L_{RSE}$ 同时约束波形与谱结构，可有效防止单一域优化导致的模式坍塌，适用于音频空间建模与声场重建任务。
2. **物理方程结构嵌入网络**：FuSNet直接用可学习卷积核参数化冲激响应方程，将声学先验转化为归纳偏置，在数据有限时仍能保持高估计精度。
3. **共享BiLSTM实现长序列压缩**：LAeNet对每个频点共享时序编码器，将变长混响序列压缩为固定维度特征，为长上下文音频建模提供低参方案。
4. **A/B麦克风分组解耦架构**：将阵列划分为接收组与参考组学习交叉映射，比全阵列联合建模更灵活，可适配异构麦克风拓扑与动态硬件配置。
5. **估计精度→下游任务闭环验证**：先用五指标严格评估ReTM估计质量，再下沉至语音去噪验证实用性，评估体系完整，值得在声学AI任务中复用。

## 关键术语表
- **ReTM (Relative Transfer Matrix)**：相对传递矩阵，描述多麦克风组间在多声源共存下的线性空间映射关系，与声源信号无关，仅依赖声源位置与房间声学。
- **ReTF (Relative Transfer Function)**：相对传递函数，单声源情形下两组麦克风响应的比值，是ReTM在$\mathcal{L}=1$时的特例。
- **SCoNet**：基于STFT域深度可分离卷积的ReTM估计网络，逐频率独立学习空间传递系数。
- **FuSNet**：基于时域可学习1D卷积滤波器组的ReTM估计网络，直接参数化冲激响应序列。
- **LAeNet**：基于共享双向LSTM的自编码器，将频点时序序列压缩后映射为ReTM系数并重构目标麦克风信号。
- **SDR (Signal-to-Distortion Ratio)**：信畸比，衡量估计信号与目标信号的功率比值（单位dB），是音频质量评估的核心指标。
