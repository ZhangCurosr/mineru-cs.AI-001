# 论文速读：Fingerprinting-Text-to-Image-Diffusion-Models-via-Collapsed

## 一句话总结
本文提出利用扩散模型的**坍塌生成（collapsed generation）**现象——即在特定输入条件下多次独立随机采样产生高度一致图像——作为非侵入式模型指纹，用于验证文生图扩散模型的所有权。该框架统一支持白盒（可控制生成管道）与黑盒（仅API访问）两种验证场景，无需修改模型参数或植入水印。

## 研究问题与动机
1. **模型泄露与版权纠纷激增**：专有文生图扩散模型常被开源分享、微调或商业化API托管，引发所有权争议，亟需有效的IP保护机制。
2. **侵入式水印的局限**：传统方法通过修改模型参数、训练目标或输出嵌入水印，带来额外计算开销、可能损害生成质量，且无法对已训练模型追溯保护。
3. **现有非侵入式指纹的不足**：白盒方法（如FingerInv、DiffIP）依赖内部表示或中间去噪状态，无法直接应用于仅暴露API的服务；黑盒方法（如TVN）使用优化的对抗提示后缀，语义异常易被检测或过滤。
4. **缺乏统一且隐蔽的验证途径**：现有方法难以在两种访问权限下使用相同的证据类型，且黑盒查询往往不够自然，易触发服务方的安全审查。

## 核心贡献（创新点）
1. **首次将坍塌生成形式化为模型内禀行为指纹**：证明易坍塌条件具有模型特异性，能够区分不同源模型，且与独立训练实例无关。
2. **提出统一的白盒/黑盒指纹构建框架**：白盒通过**截断优化**在连续嵌入空间合成易坍塌条件；黑盒通过**低损失样本挖掘**从训练动力学中筛选自然文本提示。
3. **设计基于源模型参考分布的统计检验方法**：利用正常生成参考样本建立基准，对嫌疑模型执行单侧t检验，以p值作为所有权证据，兼顾准确性与可解释性。
4. **在多种架构与混淆攻击下验证鲁棒性**：实验覆盖UNet与DiT架构，并在量化、剪枝、微调、自适应查询干扰等场景下保持高验证成功率。
5. **与已有工作的本质区别**：不同于依赖内部表示或对抗后缀的方法，本方法仅观察最终生成图像的一致性，无需访问中间状态；黑盒提示保持自然语言形式，困惑度低，更难被检测。

## 方法详解
**坍塌生成定义**：给定条件嵌入c（由文本提示p经文本编码器得到），对K个独立初始噪声x_T^(k)采样，生成图像x_0^(k)(c)，其交叉种子一致性度量为：
$$\bar{s}_\theta(c, K) = \frac{2}{K(K-1)} \sum_{i<j} s(x_0^{(i)}(c), x_0^{(j)}(c))$$
其中s为基于SSCD（自监督副本检测）的感知相似度。当$\bar{s}_\theta(c, K) \geq \tau_s$时视为坍塌。

**指纹构建**：
- **白盒（连续嵌入合成）**：初始化嵌入c_i为文本提示编码，采样K个噪声，进行截断优化：仅执行前$t_{trunc}$步去噪，最小化中间潜变量方差$\mathcal{L}_{Collapse} = \frac{1}{K}\sum_k \|x_{T-t_{trunc}}^{(k)} - \bar{x}_{T-t_{trunc}}\|_2^2$。优化后得到嵌入集$\mathcal{C}_f$。
- **黑盒（自然提示挖掘）**：利用训练过程中记录的每个样本去噪损失，筛选低损失样本对应的提示构成候选池$\mathcal{P}_{cand}$；在源模型上评估其交叉种子一致性，选取Top-M提示组成$\mathcal{P}_f$。

**验证流程**：对嫌疑模型$G_{\theta'}$，将指纹集$\mathcal{F}$（$\mathcal{C}_f$或$\mathcal{P}_f$）逐一应用，生成K个图像，计算平均一致性$\bar{s}_f$。与源模型正常生成参考分布（均值$\mu_0$，标准差$\sigma_0$）进行右尾预测t检验：
$$t_f = \frac{\bar{s}_f - \mu_0}{\sigma_0 \sqrt{1+1/N}}, \quad p_{val} = 1 - F_{t_{N-1}}(t_f)$$
若$p_{val} < \tau_f$（默认$10^{-4}$），则接受所有权声明。

## 实验与结果
- **数据集与模型**：使用公开预训练权重（Hugging Face），涵盖SD 1.4/2.1、DeciDiffusion、PixArt‑α、SD 3；微调衍生物包括SD 1.5、Deliberate v4、Realistic Vision v2.0。
- **基线对比**：白盒基线为FingerInv（基于DDPM反转的QR码恢复），黑盒基线为TVN（优化对抗提示后缀）。
- **唯一性**：在独立训练的4个条件DDPM（CIFAR‑10）及多个T2I模型上，匹配模型对的$p_{val}$显著低于不匹配对，混淆矩阵呈清晰对角线。
- **鲁棒性**：白盒下，本方法与FingerInv均在量化（BF16/INT8/FP4）、剪枝（10%~30%）、微调后成功验证；黑盒下，对GPT改写、随机Token添加（RTA）、嵌入优化（EO）、SAIL等自适应干扰均有效（$p_{val}$均低于$10^{-6}$）。
- **隐蔽性**：本方法黑盒提示平均困惑度约40~50（Mistral‑7B），远低于TVN的200~300，更易混同于普通用户查询。
- **效率**：白盒单指纹优化耗时约25秒，与FingerInv相当，远低于TVN的369秒；默认设置M=4、K=4，总查询数仅16次。
- **最强结果**：SD 1.4在SD 2.1混淆下$p_{val}=9.77\times10^{-21}$（白盒）与$1.55\times10^{-20}$（黑盒），验证信号极为显著。

## 相关工作脉络
1. **入侵式水印**（Zhao et al., Liu et al., Stable Signature）：通过在训练或解码阶段嵌入可恢复信号，需修改模型或训练流程，与本方法的非侵入式定位不同。
2. **白盒内部表示指纹**（FingerInv, DiffIP）：依赖DDPM反转轨迹或中间去噪特征，要求访问模型内部状态；本方法仅用最终图像一致性，接口要求更宽松。
3. **黑盒对抗提示指纹**（TVN）：使用优化后缀引发语义偏移，提示不自然且易被过滤；本方法利用训练动力学直接挖掘自然提示，隐蔽性更强。
4. **扩散模型记忆化研究**（Carlini et al., Somepalli et al.）：揭示模型可复现训练样本，本文将其转化为所有权验证工具，从数据提取转向模型鉴别。
5. **坍塌生成机理**（Wen et al., Jeon et al.）：分析数据重复、概率分布几何、训练动态等因素；本文将其工程化用于指纹构建，强调模型特异性。
6. **模型所有权验证协议**（Adi et al., Uchida et al.）：基于承诺机制的验证框架为本研究提供理论基础，本文扩展至扩散模型并统一白盒/黑盒场景。

## 局限性与未来方向
1. **离散化困难**：白盒优化所得连续嵌入难以映射回自然文本提示，因坍塌区域在潜空间中极为狭窄，离散化会破坏精确坐标。
2. **新模型适用性**：尽管白盒优化在严格去重的SD 3上仍有效，但黑盒自然提示的挖掘可能受限于去重策略，需要更高效的搜索机制。
3. **查询预算限制**：虽然默认16次查询较经济，但在严格速率限制的商业API中，多次独立生成可能难以实施。
4. **参考分布依赖**：验证需要源模型预先建立的正常生成参考分布，若源模型不可用则无法部署。
5. **未来方向**：探索折叠嵌入的离散优化技术；研究在流匹配、多分辨率模型上的泛化；设计更轻量级的实时验证协议。

## 研究启发与可借鉴点
1. **行为指纹而非结构修改**：利用模型固有生成特性（如坍塌、记忆化）作为指纹，避免侵入式改动，可迁移至其他生成模型（如LLM、视频生成）。
2. **截断优化降低计算成本**：仅通过早期去噪状态即可捕捉指纹特征，大幅减少梯度回溯步数，为其他基于生成轨迹的优化任务提供思路。
3. **训练动力学辅助挖掘**：将低损失样本作为高质量候选池，将复杂搜索转化为两步筛选，提高了黑盒指纹的构建效率。
4. **统一统计检验框架**：源模型参考分布结合t检验的方法，可为跨模型所有权验证提供标准化评估流程，易于复现与比较。
5. **隐蔽性优先的设计**：保持查询提示自然可读，降低被安全机制拦截的风险，对实际部署具有指导意义。

## 关键术语表
**Collapsed Generation**：在特定输入条件下，扩散模型多次独立随机采样产生高度相似输出的现象，反映模型记忆化或分布尖锐性。  
**Cross-seed Consistency**：给定同一条件，K次不同随机种子生成图像对的平均感知相似度，用于量化坍塌程度。  
**Truncated Optimization**：仅对去噪过程前$t_{trunc}$步进行优化，以中间潜变量方差近似最终输出一致性，降低计算开销。  
**SSCD Score**：基于自监督副本检测模型（Self‑Supervised Copy Detection）提取的图像表征余弦相似度，对视觉结构敏感。  
**Source‑referenced Statistical Test**：以源模型正常生成分布为基准，对嫌疑模型指纹响应进行右尾t检验，输出p值作为所有权证据。  
**White‑box Pipeline Access**：验证者可访问模型参数与中间状态，能够注入连续嵌入并控制去噪流程。  
**Black‑box API‑only Access**：验证者仅能通过文本提示提交查询，观察最终生成图像，无法访问内部表示。  
**Adaptive Query‑time Obfuscation**：嫌疑服务在接收到指纹查询时动态施加的干扰（如GPT改写、随机Token添加），试图破坏坍塌一致性。
