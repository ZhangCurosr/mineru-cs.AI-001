# 论文速读：Constructing Dynamic Master Logic Models as Knowledge Graphs for Complex System Diagnostics Using Retrieval-Augmented Large Language Models

## 一句话总结
本文提出了一种基于检索增强生成（RAG）与大语言模型（LLM）的自动化分层构建框架，能够从复杂工程系统的技术文档中提取目标-功能-结构层级关系并转化为可执行的动态主逻辑知识图谱（KG-DML）；该方法在沸水堆低压冷却剂注入系统（LPCI）案例上实现了高一致性的模型重建，并配套了融合元素级精度与结构完整性的多级评估体系与图遍历诊断交互工具。

## 研究问题与动机
- **事件驱动方法的局限性**：传统故障树分析（FTA）与事件树分析（ETA）依赖预定义的故障事件序列，难以覆盖未预想故障路径；随着系统复杂度上升，基于事件的因果追踪在工程实践中变得不可行。
- **DML 建模高度依赖人工**：动态主逻辑（DML）虽能通过目的-手段层次分解显式表达系统功能依赖，但现有构建流程完全依赖领域专家手工解读大量技术文档，耗时长达数月且难以扩展到大型系统。
- **LLM 直接构建图谱的结构脆弱性**：通用 LLM 在无约束条件下生成知识图谱易出现幻觉、推理不一致与持久化结构缺失；而工程诊断要求图谱具备严格的可遍历性与布尔逻辑保真度，普通开放域抽取无法满足。
- **功能模型自动化生成的空白**：现有 LLM 故障诊断研究多聚焦于传感器/时序数据的分类或根因挖掘，缺乏从非结构化技术文档自动生成“可执行功能模型+结构化评估+确定性推理”的完整范式。

## 核心贡献（创新点）
1. **提出了基于 RAG-LLM 的 DML 分层自动化构建框架**：按 DML 层级顺序迭代检索文档片段并生成候选节点与逻辑关系，将非结构化技术文档转化为显式功能层次图谱；与以往工作仅做开放实体抽取不同，本文通过预定义 schema 与父节点条件严格约束 LLM 生成空间，保留层次依赖与嵌套布尔逻辑。
2. **将 KG-DML 范式扩展至文档密集型复杂系统**：在前期小规模系统验证基础上，设计了批处理检索、向量存储与 Cypher 图谱合成流水线，支持核安全系统等大规模工程文档的规模化建模；其本质区别在于将“文档证据定向检索”与“层级功能分解”深度耦合，而非一次性全量生成。
3. **构建了融合元素精度与结构完整性的多级评估体系**：引入分层 Precision/Recall/F₂、逻辑门准确性及基于指数衰减惩罚的综合完整性得分（Integrity Score），能同时度量单节点准确率与端到端功能路径的结构保真度；相较于单一图质量指标，该框架更贴合诊断推理对层级一致性的严格要求。
