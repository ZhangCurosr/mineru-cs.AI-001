# 论文速读：DSAgentBench: Can Agents Automate End-to-End Data-Science Workflows in Real Computer Environments?

## 一句话总结
本文提出了 **DSAgentBench**，首个在真实操作系统环境中评估 AI 智能体能否自主完成端到端数据科学全流程的基准测试，涵盖 275 个任务覆盖数据采集、EDA、特征工程、建模、评估与可视化全生命周期；实验表明即使最强模型 Claude-4.6-Sonnet 也仅达到 56.70% 成功率，暴露出当前智能体在桌面接地、工具编排与长程推理方面的显著差距。

## 研究问题与动机
- **核心问题**：当前 AI 智能体能否在真实计算机环境中自主执行完整的端到端数据科学工作流？
- **现有基准不足一**：DS-1000、DABStep、MLAgentBench、DSBench、DSEval 等数据科学基准仅通过静态代码执行评估，不要求智能体启动应用、导航文件系统或管理依赖。
- **现有基准不足二**：OSWorld、WebArena、VisualWebArena 等 GUI 智能体基准聚焦通用桌面交互，未评估数据科学特有的分析推理与多工具协同能力。
- **现有基准不足三**：DA-CODE 虽涉及多文件分析，但仍局限于沙盒笔记本环境，缺乏操作系统访问与跨工具协调能力，无法反映真实数据科学实践的复杂性。

## 核心贡献（创新点）
1. **提出首个真实环境数据科学工作流基准**：DSAgentBench 在 Ubuntu 虚拟机中提供 VS Code、Jupyter、Chrome、SQLite、Kaggle API、OpenML 等真实工具链，支持智能体完成从数据获取到可视化的全周期任务。
2. **构建 275 个人工标注的高质量任务**：任务覆盖数据获取（DA）、探索性分析（EDA）、特征工程（FE）、建模、评估部署、可视化报告六大阶段，由两位资深标注员人工设计并经双重验证，确保可复现性与语义正确性。
3. **设计确定性执行评估框架**：引入基于 Python 的确定性评估器验证数值精度、可视化元数据（轴标签、图例、数据映射）与模型性能阈值，而非仅检查代码是否运行；LLM 视觉裁判仅在确定性验证后介入评估可视化语义对齐。
4. **系统性基准评测与误差诊断**：在 15 个闭源/开源模型上全面测试，发现开源模型成功率不足 1%，闭源模型中 Claude-4.6-Sonnet 最优达 56.70%，并通过首次失败步、工具使用模式、错误根因等维度剖析智能体在接地、规划、分析推理方面的瓶颈。

## 方法详解
- **环境架构**：基于 OSWorld 扩展，运行 Ubuntu OS，预装 Python 及数据科学库；屏幕分辨率固定为 1920×1080，观测模态支持纯截图或截图+A11y Tree（通过 AT-SPI 提取 UI 元数据，包括元素角色、边界框、交互状态）。
- **动作空间**：统一使用 PyAutoGUI 支持的鼠标操作（点击、拖拽、滚动）、键盘输入（打字、快捷键）及控制元动作（WAIT、DONE、FAIL），确保公平比较。
- **任务配置**：每个任务由三元组 $(\mathcal{C}_i, \mathcal{T}_i, \mathcal{V}_i)$ 定义，其中 $\mathcal{C}_i$ 包含初始文件系统、数据集、已安装库与应用；$\mathcal{T}_i$ 为自然语言指令；$\mathcal{V}_i$ 为确定性 Python 评估函数。
- **执行流程**：任务初始化加载虚拟机快照并执行配置脚本（如下载数据、启动应用），智能体在最多 15 步交互内感知-行动循环，终止时评估器收集产物（脚本、CSV、可视化、模型）并按任务特定规则打分。
- **评估设计**：数值任务要求结果在容差 $\epsilon = 0.01$ 内匹配；可视化任务检查文件存在性、轴标签、标题、图例与数据映射；分类任务验证准确率/F1 ≥ 0.7；成功阈值定义为评分 ≥ 0.95。

## 实验与结果
- **数据集**：DSAgentBench 共 275 个任务，来源包括 Kaggle（29.8%）、GitHub（37.1%）、OpenML（18.9%）、SQLite（7.6%）、Web API（6.5%）；模态以表格数据为主（95.3%），辅以图像（3.6%）和文本（1.1%）；难度分布 Hard 47.6%、Medium 46.9%、Easy 5.5%；多阶段任务占 56.7%。
- **基线模型**：15 个智能体，包括 GPT-4o、GPT-5-mini、GPT-5、O4-mini、Gemini-2.5-Pro、OpenAI CUA、Claude-4/4.5/4.6-Sonnet 等闭源模型，以及 UI-TARS 2B/7B、GUI-OWL-7B、OpenCUA-72B、Jedi-3B/7B 等开源模型。
- **主要结果**：闭源模型在 Screenshot+A11y 设置下，Claude-4.6-Sonnet 以 56.70% 整体成功率居首，GPT-5 为 29.81%，GPT-4o 为 24.54%，Gemini-2.5-Pro 为 20.81%；开源模型在纯截图设置下全部低于 1%（OpenCUA-72B 最高 0.73%）。人类基线三人平均达到 85.09%。
- **关键提升**：添加 A11y Tree 对闭源模型普遍有正向增益，如 GPT-5 从 23.63% 提升至 29.81%；但开源模型不支持 A11y。增加步数预算（15→50）仅带来边际提升（24.54%→25.81%），表明瓶颈不在行动数量而在推理与接地能力。
- **误差分析**：开源模型失败主因是接地错误（97-98%）；强闭源模型如 Claude-4.6-Sonnet 显示终端/代码/逻辑错误占比上升（接地 32.77%、代码 43.70%、逻辑 14.29%），说明成功需兼具稳健 UI 控制与扎实数据分析能力。

## 相关工作脉络
- **DS-1000、DABStep、MLAgentBench、DSBench、DSEval**：聚焦代码生成或孤立数据分析阶段，依赖静态执行验证，无真实 OS 交互与多工具协同能力；DSAgentBench 填补了端到端工作流评估的空白。
- **DA-CODE**：支持多文件分析与任务规划，但仍限定于沙盒笔记本环境，缺乏文件系统导航与跨应用操作；DSAgentBench 将其扩展至真实 Ubuntu 桌面。
- **OSWorld、WebArena、VisualWebArena**：评估通用 GUI 智能体在操作系统或网页中的多步导航能力，但不涉及数据科学特有的统计分析、建模与可视化推理。
- **ChartQA、Text2Vis、VisEval**：专注图表问答或可视化生成，未涵盖数据清洗、特征工程、模型训练等上游环节；DSAgentBench 将可视化纳入完整工作流末端评估。
- **KRAMABench、ARCADE**：前者面向数据湖到洞察流水线，后者为交互式数据分析，但均不提供真实桌面环境或操作系统级交互。
- **OS-ATLAS、GroundCUA、CogAgent、GUI-R1**：改进 GUI 接地的基础模型与基准，侧重界面理解而非领域推理；DSAgentBench 可作为这些模型的下游评估场景。

## 局限性与未来方向
- **开源模型评估受限**：当前开源智能体不支持 A11y Tree 输入，仅在纯截图设置下评测，无法充分反映其真实潜力。
- **误差分析样本有限**：人工检查的 604 条闭源轨迹与 150 条开源轨迹仅为全集子集，罕见失败模式可能未被捕获。
- **可视化评估偏重终态**：评估器主要验证最终产物质量（标签、映射、语义对齐），对迭代过程中的交互式图表探索与调试能力涉及较少。
- **未来方向**：扩展开源模型支持多模态观测；引入动态过程评估以捕捉分析推理链；探索强化学习或自演化机制以提升长程规划与错误恢复能力。

## 研究启发与可借鉴点
- **确定性评估器设计**：将数值容差验证、元数据检查与 LLM 裁判分阶段组合的策略值得迁移至其他代码生成或科学计算基准，平衡自动化与语义准确性。
- **人机协作任务构造**：专家主导任务逻辑设计、LLM 辅助润色与边界发现的双层管道，确保任务真实性与可执行性，可推广至其他领域基准构建。
- **A11y Tree 增强接地**：结构化 UI 元数据与视觉观测的融合显著提升闭源模型性能，提示后续 GUI 智能体研究应重视可访问性信息的集成。
- **多阶段工作流基准范式**：以"任务配置+确定性评估器"为核心的端到端评估框架，可复用于数据库管理、自动化测试、科研仿真等其他长程计算机任务场景。

## 关键术语表
**DSAgentBench**：首个在真实操作系统环境中评估 AI 智能体能否自主完成端到端数据科学工作流的基准测试平台。
**A11y Tree**：通过 AT-SPI 提取的结构化 UI 可访问性树，提供元素角色、边界框与交互状态等元数据，辅助智能体在截图中精确定位与操作。
**确定性评估器**：基于 Python 的自动评分脚本，通过数值容差、文件校验、元数据检查等规则验证任务产出，避免 LLM 裁判的主观偏差。
**工具编排**：智能体在多步骤任务中协调使用 VS Code、Jupyter、终端、浏览器、数据库等多种应用的能力。
**长程推理**：智能体在数十步交互中维持状态、处理中间错误、迭代调整策略以完成复杂工作流的能力。
**PyAutoGUI**：基准中统一使用的自动化动作接口，支持鼠标点击、键盘输入、滚动等操作，确保跨模型公平比较。

## 可复现要素
- **数据集**：DSAgentBench 包含 275 个任务，所有数据集已从 Kaggle、OpenML、GitHub、SQLite 等公开源预先下载并随基准发布。
- **代码开源**：代码库发布于 https://github.com/vis-nlp/DSAgentBench，包含任务配置、评估脚本、提示模板与推理代码。
- **关键超参**：屏幕分辨率 1920×1080，最大交互步数 15，任务超时 1800 秒，解码参数 temperature=0.1、top-p=0.9、最大输出 token 2000，动作后延迟 2.0 秒。
- **模型服务**：闭源模型通过 API 调用，开源模型在 GCP n1-standard-4 实例上使用 vLLM 引擎本地部署；完整实验配置将随代码一并公开。
