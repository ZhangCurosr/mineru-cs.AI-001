# 论文速读：Actionable Hallucination Detection: Translating Latent Uncertainty into Agentic Critique

## 一句话总结
本文提出 **Latent Critic**，一种轻量级 LoRA 适配器，与冻结的基础 LLM 并发运行并实时重构残差流几何结构，将内部接地不确定性放大为线性可分的表征，在单次前向传播内生成局部化的自然语言诊断反馈（如 `ungrounded: date`），在工具调用场景下实现低延迟幻觉拦截与零样本代理自我纠正。

## 研究问题与动机
1. **任务完成偏差导致危险幻觉**：LLM 被过度优化以遵循指令并完成下一词预测，在收到不完整用户指令时倾向于自信地编造缺失参数而非表达不确定性，在高风险代理部署中造成环境误操作。
2. **现有检测方法无法满足实时代理需求**：外部 LLM-as-a-judge 和多采样方法（如语义熵）延迟过高；且因模型对幻觉参数置信度极高，基于表面不确定性的采样方法在这些错误上几乎失效。
3. **被动探针缺乏可操作性**：内部探针虽能编码不确定性信号，但仅输出标量置信度分数，无法提供调试和纠正所需的参数级局部化反馈。
4. **核心科学问题**：能否在不引入显著推理延迟的前提下，将模型内部的不确定性翻译为可操作的局部化自然语言反馈？

## 核心贡献（创新点）
1. **Latent Critic 架构设计**：首次通过并发的 LoRA 适配器实时重写 Transformer 残差流，将接地不确定性几何结构放大为线性可分的表示，在单序列内完成检测与定位，而非依赖多轮采样或外部 judge。
2. **遮蔽诊断训练目标（Masked Diagnostic Objective）**：在损失计算中完全遮蔽基础模型的工具调用生成过程，仅在 `[POS]` 触发令牌及其后续诊断标签上计算梯度，迫使适配器专注于不确定性提取而非参与表面文本生成。
3. **机制层面的因果验证**：通过激活补丁（activation patching）与层-wise 探针分析，证明适配器以秩无关（rank-invariant）方式重塑底层几何结构，且该线性可分表示具有跨分布迁移的稳定性，而非死记分类器。
4. **闭环代理自我纠正的端到端验证**：在 ReAct 环境中部署，Specific 干预将参数级 F1 提升至 61.2%，同时将误拦截率降至 2.9%，并显著降低重试轮数；延迟开销仅 <10 ms（vLLM 部署）。

## 方法详解
1. **并发双流架构**：Latent Critic 是一个冻结基础模型之上的 LoRA 适配器（r=64, α=128），与主模型同时处理相同输入 token。在代理循环中，基础模型自回归生成工具调用 JSON 语法，适配器的中间输出在此阶段被丢弃，仅用于累积和重构内部表示。
2. **触发令牌 `[POS]` 与注意力汇点**：工具调用完成后，附加结构化的 `[POS]` token，该 token 作为注意力汇点建立计算边界，指示适配器在此刻聚合整个工具调用上下文的不确定性并生成诊断字符串（如 `ok` / `wrong_tool` / `ungrounded: date`）。
3. **遮蔽损失函数**：标准 SFT 损失被修改——基础工具调用的所有 token（包括 JSON 语法与参数值）均被 mask，梯度仅回传到 `[POS]` token 及其标签。这确保适配器不干扰主模型的生成能力，同时被强制聚焦于提取接地信号。
4. **训练配置**：目标模块为 `q_proj, k_proj, v_proj, o_proj`，学习率 $2 \times 10^{-5}$，batch size=32，3 epoch，AdamW 优化器，余弦退火 + warmup（ratio=0.05）。训练耗时约 3–5 GPU 小时（单卡 A100 80GB）。

## 实验与结果
- **数据集**：训练 5,000 场景；ID 评估 500 场景（含 3 类：ok / ungrounded / wrong_tool）；OOD 评估 200 场景（来自 ToolAlpaca，含未见过 API schema）。
- **基线**：Token Entropy、Semantic Entropy、SEP、Linear Probe（SVM）、External Judge（同规模 Qwen 3.5 4B，同等 LoRA 配置）。
- **ID 检测性能（Qwen3-4B）**：Latent Critic 取得 **AUROC 0.966**、**F1 0.870**、**AUPRC 0.924**；参数级精确匹配准确率达 **83.8%**。
- **OOD 检测性能（Qwen3-4B）**：AUROC 0.925，F1 0.670，AUPRC 0.815；在 1% FPR 的严格安全预算下仍保持 38.9% TPR。
- **跨模型复现（Llama-xLAM-2-8B）**：ID AUROC 0.926 vs Linear Probe 0.833，OOD AUROC 0.649 vs 0.514。
- **闭环代理实验**：Specific 干预下 ID 参数级 F1 = **61.2%**（vs Generic 51.3% / Base 52.1%），误拦截率降至 **2.9%**（vs Generic 9.4%），轨迹成功率 22.1%；自我恢复率提升至 37.0%（ID），平均失败重试次数降至 1.06 次。
- **最强结果与提升幅度**：相比 External Judge，Latent Critic 在 Qwen3-4B 上 AUROC 提升 5.1 个百分点（0.915 → 0.966）；相比 Passive Linear Probe，ID AUROC 提升 18.4 个百分点（0.782 → 0.966），且 OOD 泛化差距更为悬殊（0.616 → 0.925）。

## 相关工作脉络
1. **LLM-as-a-Judge / 外部评价器**（Darwish et al., 2025）：基于表面文本二次推理，延迟高且受置信度校准差的影响；本文定位为"在同一前向传播中直接读取内部表示"。
2. **语义熵 / 多采样不确定性估计**（Ji et al., 2023; Kossen et al., 2024）：对任务完成偏差导致的幻觉失效（模型对幻觉参数置信度极高，熵值低）；本文证明表面 logits 的接地概率密度与真实情况高度重叠。
3. **被动内部探针**（Azaria & Mitchell, 2023; Orgad et al., 2025）：输出标量分数，无参数级局部化能力，且在分布迁移下 AUROC 从 0.782 跌至 0.616；本文通过几何重构实现稳定的线性可分表示。
4. **推理时干预（ITI）**（Li et al., 2024）：需遍历多层/注意力头进行干预，实现复杂；本文使用低秩适配器，仅需修改单一流路径。
5. **暂停令牌（Pause Tokens）**（Goyal et al., 2024）：引入额外计算步骤用于反思；本文借鉴其结构思路，但将额外步骤用于不确定性累积而非单纯引入延迟。
6. **机制可解释性框架**（Burns et al., 2024; Marks & Tegmark, 2024; Meng et al., 2023）：证明残差流中存在线性可分的真实/不确定性几何；本文将这一发现工程化为可部署的 PEFT 适配器。

## 局限性与未来方向
1. **标注依赖程序化模拟用户**：训练标签由 Qwen3.5-122B 模拟用户生成（人工复核率 89%），评估集仅经单一标注员验证；扩展至开放生成（span-level 定位）仍是开放挑战。
2. **检测能力受限于基础模型内部状态**：若基础模型自身崩溃（如 runaway generation 无限循环），残差流几何结构被破坏，Critic 无法可靠检测；检测上限受冻结模型能力约束。
3. **分布迁移下的模型依赖性**：在 Llama-xLAM-2-8B 上，Critic 与 External Judge 的 OOD AUROC 相近（0.649 vs 0.630），表明内部访问优势并非在所有架构下都显著。
4. **下游自我纠正能力受限**：部分轨迹无法恢复（如 D.1 所示的顽固猜测循环或任务放弃），说明现有冻结模型的对话政策不足以充分利用诊断反馈，需专门训练恢复策略。
5. **未来方向**：向开放生成场景的 span-level 定位扩展；针对诊断反馈的恢复策略微调；在更多架构与更大规模代理工作流中验证。

## 研究启发与可借鉴点
1. **遮蔽诊断目标的可迁移设计**：将 SFT 损失仅约束在特定触发 token 上、而完全遮蔽主生成过程的训练范式，可推广至需要同时执行任务与提供可解释诊断的其他场景（如代码生成中的安全审查、摘要生成中的事实核查）。
2. **触发令牌作为结构化注意力汇点**：在序列末端插入专用 token 以聚合上下文信息并触发次级输出，是一种简洁的"事后反思"架构模式，可借鉴于需要并发执行的监控/评估模块设计。
3. **参数级评估指标的细化**：从轨迹级二值成功转向参数级 Precision/Recall/F1，更精确地解耦安全（Precision）与功能（Recall）的权衡，为代理安全评估提供了更细粒度的度量框架。
4. **低秩不变性的发现**：证明接地信号存在于低维子空间中，即使 r=4 也能有效分离，为资源受限设备的实时部署提供了理论依据，提示我们无需大秩适配器即可实现有效的表征重构。
5. **机制分析+实证验证的双轨范式**：结合探针可分离性分析、激活补丁因果验证与大规模基准实验，为 PEFT 适配器的"为何有效"提供了完整的可解释性论证模板。

## 关键术语表
- **Latent Critic**：并发的 LoRA 适配器，通过实时重写 Transformer 残差流将内部接地不确定性放大为线性可分的表征，并在单序列内输出局部化自然语言诊断。
- **任务完成偏差（Task-Completion Bias）**：LLM 因过度优化指令遵循和下一步词预测而产生的倾向，导致模型自信地编造缺失参数而非请求澄清。
- **规格接地（Specification Grounding）**：代理生成的工具调用参数是否能在用户对话历史中找到显式或隐式依据，区别于基于外部事实核查的事实性幻觉。
- **完成规格列表（Completed Specifications List, CSL）**：由模拟用户维护的二进制掩码，逐轮跟踪每个参数是否已在对话中被用户提供（1=已提供，0=未提供）。
- **触发令牌（[POS] Token）**：附加在工具调用 JSON 后的特殊 token，作为注意力汇点建立结构边界，触发适配器聚合上下文不确定性并生成诊断标签。
- **激活补丁（Activation Patching）**：跨轨迹替换中间层隐藏状态以验证因果关系的机制分析技术，证明 Critic 的分类依赖底层几何而非表面文本。
- **秩无关重构（Rank-Invariant Restructuring）**：适配器以低秩方式将不确定性几何结构转化为线性可分表示，不同 LoRA rank（如 r=4 至 r=64）均能有效分离该子空间。

- **代码/权重**：论文未提及开源（代码与权重未公开）。
- **关键超参**：LoRA rank=64，alpha=128，学习率=2e-5，batch size=32，epochs=3，target modules=[q_proj, k_proj, v_proj, o_proj]，AdamW 优化器，余弦退火调度，warmup ratio=0.05，触发 token=`[POS]`，遮蔽 loss mask 启用。
