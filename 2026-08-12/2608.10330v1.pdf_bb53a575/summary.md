# 论文速读：Hierarchical Compositionality for An Assistive AI Agent

## 一句话总结
本文提出了一种面向辅助AI智能体的分层组合消歧架构，通过ASP非单调逻辑可行性过滤与三路启发式评分（语义兼容性、会话显著性、用户主题偏好）相结合，在低资源交互历史下实现对模糊指令的快速个性化解析，并在模拟家庭环境中显著优于同等输入信息的GPT-5.1等数据驱动基线。

## 研究问题与动机
- **现代神经智能体的固有缺陷**：LLMs/VLMs虽在感知与推理任务上表现优异，但资源消耗大、黑盒性强，且在面对未见情境时易因底层表征与处理路径的局限性而做出武断决策。
- **模糊指代的个性化消歧难题**：用户日常指令常含欠指定引用（如“放一个水果在桌上”），现有方法多依赖FM内部编码或当前视觉特征，缺乏对用户长期偏好与习惯的建模，频繁请求澄清会加重用户认知负担。
- **现有工作的迁移与泛化瓶颈**：既有消歧或用户建模研究多直接存储对象级历史记录或显式偏好，证据无法跨实体转移；当测试目标在历史中未直接出现时（如新奇物体），性能急剧退化。
- **早期AI原则的现代回归**：本文受Herb Simon等有界理性先驱启发，主张将迭代组合性、生态理性与交互式学习等基本原则重新嵌入智能体架构，以轻量启发式替代纯参数拟合，实现开放环境下的快速适应。

## 核心贡献（创新点）
1. **三层分层组合表示（L0/L1/L2）**：自动构建从原子属性到领域概念再到用户工作流模式的层次化表征，使智能体能够通过共享概念将高频实体的用户偏好迁移至低频或全新实体。与仅依赖对象ID或原始属性堆叠的基线相比，本质区别在于通过统计显著的共现组合实现了跨实体的证据传播。
2. **三路互补启发式评分与动态澄清机制**：提出语义兼容性、会话显著性与用户主题偏好三信号融合排序框架，并引入置信度领先阈值触发澄清。与纯数据驱动的LLM路由或单一上下文信号相比，显式建模了语言语义、短期注意力与长期习惯的互补性，兼顾准确率与人机交互效率。
3. **ASP符号过滤与非单调推理嵌入**：将Answer Set Programming作为流水线前端的可行性过滤器与规划器，严格排除违反领域公理、状态约束与执行条件的候选解释。与纯概率/神经方法相比，其本质优势在于保障了解空间的符号正确性与可审计性。
4. **系统性评估与强基线对比**：在66实体模拟家庭环境中设计四级歧义梯度评测，证明该方法在不同模糊程度下均稳定优于全信息GPT-5.1（±CoT/ASP过滤），并揭示了组合表征对罕见实体的显著增益与强用户特异性。
