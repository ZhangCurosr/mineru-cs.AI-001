# 论文速读：MAP-Graph: Provenance-Aware Shared Memory for Multi-Agent Workflows

## 一句话总结
论文提出 MAP-Graph，一种面向多智能体工作流的**溯源感知共享记忆层**，通过将智能体、源文档、记忆、主张与行动编码为类型化执行图，实现了语义检索与权限/风险感知的分离决策；在 2700 个合成任务上达到 **94.96% 任务成功率**与 **0% 攻击成功率**，显著优于现有基线。

## 研究问题与动机
- **共享记忆的安全盲区**：多智能体工作流中，一个智能体的记录可决定另一个智能体的回答或工具调用，但现有向量检索仅返回"最相关"记录，无法判断该记录对特定智能体或行动是否**合法可用**。
- **派生过程隐藏限制**：对私密、投毒、不可信或被撤销来源的总结可能遮蔽原始限制条件，导致派生记忆高度相关却支撑了未授权读取或危险操作。
- **现有方法各有偏重但互不覆盖**：私密/共享记忆分层、图谱结构化记忆、溯源追踪各自解决部分问题，但未在统一框架下分离**硬性授权**与**梯度信任**，也未将证据要求与行动风险动态匹配。
- **三个核心挑战（C1-C3）**：(C1) 递归祖先——限制条件沿多步派生链传递，仅检查本地元数据不足；(C2) 异构约束——权限决定能否检索，来源可靠性等信号应梯度降权而非直接过滤；(C3) 行动依赖的准入性——低风险的回答可能足以支持，但高风险行动需要更强的证据基础。

## 核心贡献（创新点）
1. **形式化溯源感知共享记忆为可控决策问题**，严格区分语义相关性（检索阶段）与智能体/行动特定的溯源准入性（决策阶段）。
2. **提出 MAP-Graph 框架**，融合类型化溯源表示、权限硬过滤、基于祖先链的乘法路径信任重排、行动时间门控及审计保真的后代标记机制。
3. **设计三域可控合成基准**（2700 任务、7 基线、6 消融、3 大模型 Backbone 迁移测试），填补了在统一条件下对比不同记忆治理策略的实验空白。
4. **证明纯检索策略的指标陷阱**：移除权限过滤器后 TSR 从 94.96% 升至 96.00%，但非授权访问率升至 100%，说明单一效用指标会掩盖安全失败。

## 方法详解

**整体架构**：每个任务独立维护一个 NetworkX MultiDiGraph（溯源执行图谱）和一个 Chroma 向量集合，通过统一 memory id 耦合两种表示。

**图 Schema（§3.1）**：8 类节点（User, Agent, Tool, Resource, Message, Memory, Claim, Action）+ 10 类边（authorized_by, observed_from, forwarded_to, derived_from, summarized_from, written_by, read_by, verified_by, invalidated_by, used_for_action）。派生类边使祖先链可从单点导出，是 C1 评估的前提。

**记忆构造与溯源捕获（§3.2）**：agent 观察源/工具输出时创建派生记录；派生记忆的权限作用域为所引用记忆作用域的**交集**；显式 revoke 事件清空源权限并更新直接引用记录，其他后代在信任递归计算时检测。

**溯源感知检索（§3.3）**：对查询 q 和智能体 a，先计算硬性权限筛选集 $\mathcal{C}(a)=\{m:\text{CanRead}(a,m)=1\}$，再对每条候选计算：

$$\mathrm{Score}(m,q,a)=s(m,q)\cdot\rho(m,a)$$

其中 $s(m,q)=\max(0,1-d(m,q))$ 为余弦相似度得分，$\rho(m,a)$ 为路径信任的乘积衰减：

$$\rho(m,a)=\mathrm{clip}_{[0,1]}\big(S(m)\cdot I(m)\cdot F(m)\cdot P(m,a)\cdot V(m)\cdot A(m)\big)$$

各因子含义：S（源信任，取祖先最小值）、I（路径完整性，投毒/私密/撤销各乘一次相应惩罚）、F（变换损失因子）、P（当前 CanRead 硬判决）、V（验证加成）、A（写入者可靠性）。top-5 高分记录返回。

**行动时间门控（§3.4）**：动作提议后，对支持的记忆重新计算信任，按风险阈值 $\theta$（回答=0.30，高风险非回答=0.85，其他=0.60）应用四条确定性规则返回 Allow/Block/Redact/Reverify/AskUser。受影响的祖先链保留而非删除，用于审计追踪。

## 实验与结果

**数据集**：2700 个合成任务（seed 42），均匀分布于企业工作流、软件工程、研究助理三域，每域每实验组 15 个语义族×10 变体；共 960 Allow、1140 Block、210 Reverify、390 Redact 标签。

**基线（7 个）**：B0 无记忆、B1 共享向量、B2 隔离向量、B3 改编 G-Memory、B4 改编 Collaborative Memory、B5 改编 MemLineage、B6 平铺元数据控制。

**主要结果（Table 1）**：

| 方法 | TSR ↑ | Acc ↑ | Clean ↑ | Unsafe ↓ | ASR ↓ | Leak ↓ | UAcc ↓ | Revok ↓ |
|------|-------|-------|---------|----------|-------|--------|--------|---------|
| B6（最强基线） | 74.67 | 46.41 | 88.00 | 20.81 | 36.44 | 20.44 | 43.08 | 39.33 |
| **MAP-Graph** | **94.96** | **72.70** | **90.22** | **1.52** | **0.00** | **0.00** | **0.00** | **0.00** |

MAP-Graph 相对 B6 TSR 提升 **20.29pp**，相对 B5（最强 Acc 基线 51.07%）Acc 提升 **21.63pp**；Clean TSR 90.22% 表明安全增益并非简单拒答干净请求。ASR/Leak/UAcc/Revok 四项安全指标均降至 **0%**。

**Backbone 迁移（Table 3，540 任务子集）**：在 Qwen2.5-7B、GLM-4-9B、Llama-3.1-8B 三个大模型上，MAP-Graph 均获得最高 Acc，且零非授权访问；Qwen 和 Llama 上 TSR 领先，GLM 上 TSR 86.30% 略低于 B6 的 88.89%，暴露效用-安全权衡。

**消融（Table 2）**：移除行动时间门控使 ASR 升至 34.89%；移除权限过滤器后 TSR 升至 96.00% 但 UAcc 升至 100%；移除溯源栈使 TSR 降至 67.89%、UAcc 100%。证明各组件贡献独立且不可相互替代。

## 相关工作脉络
- **Agent 记忆系统**（G-Memory, Collaborative Memory, MemLineage, Governed Shared Memory）：本文在统一基准下对比这些系统的机制差异，强调本工作同时覆盖硬权限过滤、递归梯度信任与行动时间门控，而前作各自只覆盖其中一部分。
- **编排与检索**（RAG, Graph RAG）：现有工作聚焦语义增强与多跳覆盖，本文则侧重执行谱系的 Governance 与审计，而非通用语义图谱构建。
- **溯源与证据追踪**（W3C PROV, Poisoned Memory 研究）：W3C PROV 形式化派生关系，Poisoned Memory 研究揭示 LLM 证据使用缺陷；本文不追求自动真理维护，而是将谱系作为**运行期控制信号**操作化。
- **Goverened Shared Memory**（Margalit et al. 2026）：生产级系统但仅做 live 系统评估，未在可控条件下量化硬性授权、梯度祖先信任与行动风险门控的交互效应——本文正好填补此空白。

## 局限性与未来方向
- **合成基准限制**：2700 任务均为模板化生成，行动为模拟执行，每任务固定四智能体单轮交互，无法直接外推至部署级场景。
- **单次运行结果**：每方法单 seed 单次运行，TSR 与 Acc 的置信区间反映簇内案例变异性，而非模型推断不确定性。
- **B3-B5 为适配而非完整复现**：部分机制（如 G-Memory 的轨迹稀疏化、Collaborative Memory 的 per-task 访问图）被替换为确定性版本，对比存在偏差。
- **未评估推理非确定性**：temperature=0 单样本不估计推理随机性；约 3.89%-9.08% 的外层调用触及 2048 token 生成上限。
- **跨会话累积未覆盖**：图谱与向量集在每个任务间重置，结论聚焦任务内协调而非跨会话知识积累。
- **行动时间阈值仍是主要剩余弱点**：Exp-5 中仍有 41/450（9.11%）的不可准入 Allow 决策。

## 研究启发与可借鉴点
1. **检索 ≠ 授权**的分离设计原则：将硬权限过滤（CanRead）与梯度信任评分（ρ）在公式层面分解，避免将权限折叠为惩罚项后被语义相似度反超——这一设计可直接迁移至任何带访问控制的 RAG/记忆系统。
2. **乘法路径信任的级联衰减模型**（S×I×F×P×V×A）：为多智能体系统中的证据可信度传播提供了简洁、可审计的数值框架，各因子有明确语义且可独立扩展。
3. **行动时间门控（Action-Time Gating）**：在检索阶段之后、执行阶段之前引入基于行动风险的二次评估，解决了"同一份证据对回答够用但对高风险操作不够"的粒度问题，值得推广到工具调用安全策略。
4. **受影响谱系保留而非删除**的设计：被阻断的记录仍保留祖先链用于审计，兼顾了安全性与可追溯性，这对合规性敏感的应用场景具有参考价值。
5. **合成基准的结构化评估**：六组实验（清洁效用、投毒传播、私密泄露、权限撤销、行动风险敏感性、压缩开销）×三域的矩阵设计，为记忆治理研究提供了可复用的评估范式。

## 关键术语表
**Provenance-Aware（溯源感知）**：记忆系统不仅存储内容，还记录内容的来源、派生链与权限信息，以便在检索和决策时进行安全治理。

**Path Trust（路径信任）**：沿派生链从源到当前记忆的乘法信任衰减因子，综合源可信度、路径完整性、变换损失等多维度信号。

**Action-Time Gating（行动时间门控）**：在智能体提议行动后、实际执行前，基于支持记忆的信任分数与行动风险阈值进行二次准入决策的机制。

**Containment（ containment / 影响隔离）**：被阻断的派生记忆保留其谱系链用于审计，但不允许下游使用，实现"阻断而非删除"的治理策略。

**Unsafe Rate（不安全率）**：所有任务中模拟执行事件的比例（当 oracle 决策为 Block/Redact 时），衡量系统的实质安全边界。

**Attack Success Rate (ASR)**：投毒记忆组的 Allow/执行率，衡量系统抵御投毒传播的能力。

**Task Success Rate (TSR)**：oracle-Allow 用例必须 Allow，否则安全干预即视为成功的宽松成功指标，反映效用-安全的综合权衡。

**Flat Provenance Baseline (B6)**：保留每条记录的本地元数据（可见性、权限、信任标签等）但不构建溯源图、不递归遍历父记录的控制基线，用于隔离图谱结构的价值。

## 可复现要素
- **数据集**：合成基准，论文提供 seed 42（全量 2700 任务）与 seed 2027（迁移子集 540 任务），构造细节见 Appendix C。
- **代码/权重**：论文未提及开源仓库；使用了 OpenAI-compatible client（AutoGen）与 Qwen2.5-7B-Instruct/GLM-4-9B-0414/Llama-3.1-8B-Instruct 三个商业/开源模型。
- **关键超参**：Embedding 使用 BAAI/bge-small-en-v1.5（归一化），k=5；温度=0；生成上限 2048 tokens；路径信任阈值 θ 分别为 0.30（回答）、0.60（低风险/中风险）、0.85（高风险）；最大检索记录数 5。
