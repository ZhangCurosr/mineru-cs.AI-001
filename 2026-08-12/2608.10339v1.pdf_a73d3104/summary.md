# 论文速读：Expert-Guided g-computation with Large Language Models for Estimating Causal Effects on Timings: Applications to Hospital Quality Improvement

## 一句话总结
本文提出 **expert-guided g-computation（egg-computation，专家引导的g计算）**，将甘特图与因果DAG结合，利用大型语言模型（LLM）辅助实现患者层面的个性化因果图构建与事件时间模拟，从而在无历史干预数据的条件下准确估计医院质量改进（QI）干预措施对平均住院时长（LOS）节省的因果效应。仿真表明在患者异质性因果结构下，该方法可消除传统单一DAG方法高达14小时的估计偏差；在真实医院数据上的实验显示，LLM生成的因果图与人类专家高度一致，且按期望影响排名前三的干预措施获得了临床专家的高度认可。

## 研究问题与动机
- **核心问题**：医院QI项目面临多个候选干预措施，但现有方法难以估计和排序这些干预措施对关键指标（如平均住院时长LOS）的因果效应，导致无法科学决策。
- **定性方法的局限**：传统基于甘特图/价值流图的专家判断易受认知偏差影响——上游事件的时移未必能传导至下游（如提前社会工作者会诊可能因关键信息未就绪而无法真正加速出院）。
- **定量方法的不足**：
  1. 回归模型仅估计关联而非因果；
  2. 正性假设（positivity）难以满足，因为候选QI干预是尚未实施的全新政策，无历史对照数据；
  3. 干预覆盖异质性人群，统一因果图几乎不可构建，且数据不足以准确估计条件关系。
- **动机**：结合定性与定量方法的优势——在数据无法识别的地方依靠专家推理，在专家能力有限的数据充分区域依靠统计建模，并以甘特图为桥梁建立形式化因果语义。

## 核心贡献（创新点）
1. **首次为甘特图建立因果模型**：将甘特图中的事件节点映射为以等待时间（waiting time）为变量、满足局部马尔可夫性质的DAG，赋予其形式化的概率与因果语义，并证明在经典因果假设下可识别"平均节省时间"（average time saved）这一目标估测值。
2. **提出egg-computation框架**：将g-computation扩展为针对甘特图的时间顺序过程，根据节点相对于干预的位置将其分为Type I/II/III三类，分别采用事实复制、统计建模和专家分布采样进行反事实模拟，并给出无偏估计的理论保证（Theorem 3.1）。
3. **开发LLM辅助的自动化流水线**：设计五步LLM prompt pipeline完成患者层面的DAG构建（涵盖候选干预适用性判定、节点/边抽取、因果推理与结构化验证），以及针对Type II/III节点的时序预测模块（支持传统回归与ICL三选一），无需微调即可适配新临床场景。
4. **在两个层次的实证验证**：仿真研究量化了在患者异质性因果结构下，单一共享DAG方法偏差可达14小时而方法提出的方法偏差为0；真实世界研究在旧金山ZSFG医院的2,193条患者时间线上对11项候选QI干预进行评估，LLM与专家生成DAG的一致性高（节点特异性96.5%，边精度91.8%–94.2%），且按期望影响排名的前三项获得了四位临床专家的认可。

## 方法详解

### 因果模型（甘特图→DAG的映射）
- 设患者基线特征为 $X$，事件集合为 $\mathrm{D} = \{0, 1, \ldots, K\}$（拓扑序），其中 $k=0$ 为入院（源节点），$k=K$ 为出院/死亡（汇节点，即结局 $Y = T_K$）。
- 事件 $k$ 的墙壁时间 $T_k$ 与等待时间 $W_k$ 的关系（式2.1）：
  $$T_k = \max_{j \in \mathrm{Pa}(k)} T_j + W_k \quad (\mathrm{Pa}(k) \neq \emptyset), \qquad T_k = W_k \quad (\mathrm{Pa}(k) = \emptyset)$$
- 局部马尔可夫性质（式2.2）：$W_k \perp T_{\mathrm{Nd}(k)} \mid T_{\mathrm{Pa}(k)}, X, \mathrm{D}$。
- 引入干预节点 $A \in \{0,1\}$（$A=1$ 为新QI政策），定义潜在等待时间 $W_k(a)$ 和潜在墙壁时间 $T_k(a)$（式2.3）。
- 核心定理估计量：$\tau = \mathbb{E}[Y(0) - Y(1)] = \mathbb{E}T_K - \mathbb{E}[\mathbb{E}[T_K(1) \mid X, \mathrm{D}]]$，识别关键是将反事实联合分布分解为因果因子（式2.5）。

### 关键假设
- **假设1（一致性）**：$T_k = T_k(0), W_k = W_k(0)$。
- **假设2（外生干预）**：$W_k(a) \perp A \mid X, \mathrm{D}$。
- **假设3（排除约束）**：Type I节点（非后代）$W_k(1) = W_k(0)$；Type II节点（后代但非直接子节点）条件分布不变。
- **假设5（专家DAG正确性）**：专家给出的患者特异性DAG与真实因果结构一致。
- **假设6（时序模型正确性）**：Type II节点的统计模型等于真实条件分布。
- **假设7（专家反事实模拟正确性）**：专家提供的Type III节点分布等于真实反事实分布。

### egg-computation三步流程（Box 中描述）
1. **DAG构建**：专家判断干预是否适用于该次住院，并按拓扑序确定所有节点类型（Type I/II/III）。
2. **反事实模拟**（按拓扑序逐节点计算）：
   - **Type I**（干预的非后代节点 $k \in \mathrm{Nd}(A)$）：直接复制事实时间，$W_k(1) = W_k$。
   - **Type II**（干预的后代但非直接子节点 $k \in \mathrm{De}(A) \setminus \mathrm{Ch}(A)$）：使用基于观测数据训练的时序模型，以已修改的父节点时间为条件，预测 $W_k(1)$。
   - **Type III**（干预的直接子节点 $k \in \mathrm{Ch}(A)$）：从专家提供的分布 $p_{\mathrm{expert}}$ 中采样 $W_k(1)$。
3. **估计量计算**：$\hat{\tau} = \frac{1}{n}\sum_{i=1}^n (Y_i - Y_i')$，其中 $Y_i'$ 为反事实LOS。Theorem 3.1保证在假设1-7成立时 $\hat{\tau}$ 是无偏估计。

### LLM辅助流水线（Section 3.2）
- **步骤1（DAG构建，五步LLM调用）**：
  - Step 1：自由形式临床推理，识别入院→出院路径上的关键事件及候选混杂因素（遵循disjunctive criterion向后追溯）。
  - Step 2-3：将推理结果形式化为Gantt图（先确定节点集，再确定边）。
  - Step 4-5：将图编码为结构化格式（先生成节点列表，再生成边列表），要求LLM输出必须包含患者记录中的原文引用，确保可审计性。
  - 自动后处理：拓扑排序检查环路、时间戳一致性校验、单轮自动修复尝试。
- **步骤2（时序模拟）**：
  - Type III：通过详细prompt指定干预细节（动机、规则、示例时间、纳入/排除标准），必要时结合少量真专家标注做迭代校准。
  - Type II：三种方案对比——（a）传统表格回归（Ridge/Random Forest/Embedding+Ridge）；（b）在上下文学习（ICL）中直接以GPT-5做few-shot预测；三种方案通过交叉验证选择。

## 实验与结果

### 仿真研究（Section 4.1）
- **设定**：$n=4,000$ 名患者，每名患者的因果图随机包含CT→MRI或MRI→CT依赖关系（各占一半），干预为将CT或MRI报告生成时间上限设为12小时。
- **结果（表1）**：
  - **DAG-extractor + Gantt-timing（oracle）**：偏差 = $0.00 \pm 0.00$ 小时（两种干预均为0，理论最优）。
  - **DAG-extractor + OLS-timing**：偏差仅 $-0.35 / -0.22$ 小时。
  - **DAG-extractor + kNN-timing**：偏差 $2.75 / 2.11$ 小时。
  - **Single-DAG（错误结构）+ Gantt-timing**：偏差高达 $13.01 / -2.56$ 小时（CT→MRI假设下对Priority-CT）和 $-5.37 / 14.19$ 小时（MRI→CT假设下）。
  - 结论： imposing一个错误的单一DAG导致最大14小时的严重估计偏差，而患者特异性DAG提取器即使配合 imperfect timing model 也仅引入 < 0.4 小时偏差。

### 真实世界评估（Section 4.2，ZSFG医院）
- **数据**：2,193条成人住院时间线（5种最常见诊断），11项候选QI干预，共生成1,531个LLM DAG（每诊断组/干预最多30例）。API总成本 $490。
- **专家与LLM一致性（表2）**：
  - 早期出院计划：节点特异性96.5%，节点召回88.9%，边精度91.8%，边召回80.2%。
  - 关键成像优先：节点特异性96.5%，节点召回95.7%，边精度94.2%，边召回86.0%。
  - 重新运行egg-computation于LLM生成vs专家修正DAG：平均节省时间差异分别为 $-2.6$ 小时和 $+8.1$ 小时；24对中有19对给出完全一致的估计。
- **Type II时序模型精度（表3）**：ICL（GPT-5）达到最低MAE = **24.12小时**，优于零延迟基线（28.30）、对中位数（27.23）、Ridge（34.30）、随机森林（36.58）、Embedding+Ridge（33.79）。
- **干预排名（表10 / 图5）**：
  - 按期望影响（资格率 × 人均节省时间）排名前三：**Consult response escalation（18.9 h）**、**Disposition-critical imaging priority（15.6 h）**、**Early discharge planning（10.8 h）**。
  - 排名稳定性：2,000次bootstrap重采样中，前三位相同的概率达89%。
  - 四名临床专家在"不看估计排名"的情况下，三人将Consult response escalation排在第一，与egg-computation估计排名一致；仅1名专家将Early discharge planning列为第一。

## 相关工作脉络
- **经典g-computation（Robins, 1986）**：本文在其基础上扩展，专门针对时间顺序过程（甘特图/事件序列）而非离散时间网格，并引入专家/LLM作为数据不足区域的补充信息源。
- **因果发现与LLM（Kıcıman et al., 2024; Antonucci et al., 2024; Cotta et al., 2024）**：前人工作主要用LLM从文本推断成对因果或提取混杂因子后套用传统因果推断；本文的独特定位是LLM直接参与生成患者级因果图 + 模拟反事实轨迹，形成端到端的专家引导因果推理。
- **Lean医疗与价值流图（Vidal-Carreras et al., 2022; Rother & Shook, 1999）**：传统定性分析用甘特图映射患者流程但缺乏因果识别保障；本文首次将甘特图嵌入因果DAG框架并证明可识别性。
- **连续时间因果图（Didelez, 2008; Røysland et al., 2025; Wald et al., 2024）**：关注连续时间事件过程的图模型；本文与之区别在于强调患者异质性DAG和专家/LLM辅助信息补充，而非纯数据驱动的图学习。
- **LLM在因果推断中的作用（Liu et al., 2025）**：综述指出LLM可用于因果发现和模拟专家推理；本文是该方向的具体落地实践，提出了一套完整的prompt工程方案。
- **先前LLM辅助QI分析（Vossler et al., 2026）**：同一团队此前用LLM从医院记录中提取阻塞/延迟瓶颈并生成候选QI清单；本文在此基础上向前推进一步，对这些候选措施进行因果效应估计与排序。

## 局限性与未来方向
- **资源约束被忽略**：当前估计量假设干预资源充足（上界估计），未建模不同患者间对共享资源（如放射科设备、社工）的竞争；未来需联合批量患者进行模拟。
- **置信区间未完全解决**：目前估计缺乏同时考虑样本变异和专家输入不确定性的正式置信区间构造程序。
- **干预可能改变事件集合**：若干预大幅改变患者轨迹（如化疗改手术），则假设D(0) = D(1)不成立，框架不适用（见Remark 2.1）。
- **专家准确性假设无法检验**：Assumption 5（专家DAG正确性）和Assumption 7（专家时序分布正确性）均不可从数据中验证，实际性能依赖专家/LLM对齐质量。
- **患者特异性DAG构建的扩展性**：每例需多步LLM调用（~14节点/21边），对超大规模队列的计算成本可能较高（虽当前单例约14美分，但仍需权衡）。

## 研究启发与可借鉴点
1. **"类型划分+差异化信息源"的设计范式**：将节点按与干预的因果关系分为三类，对每一类选择最优信息来源（事实复制/统计建模/专家推理），这一思路可迁移至其他需要混合专家知识与观测数据的可识别因果推断场景。
2. **五步分阶段LLM prompt工程**：从自由推理→节点提取→边提取→结构化编码→验证的链式设计，前期步专注"推理"后期步专注"格式化"，有效利用LLM reasoning tokens；该模式可复用于其他需要复杂结构化输出的LLM应用。
3. **ICL用于时间间隔预测**：将Type II等待时间的预测问题转化为few-shot in-context learning任务，在复杂、噪声大的临床时序数据上优于传统回归模型，提示对低结构化数据的时间预测问题可优先考虑ICL方案。
4. **LLM生成的可审计性设计**：要求LLM输出必须包含原始记录的原文引用（verbatim quotes），使因果图节点和边可追溯；这一设计对所有涉及LLM生成可信结构化内容的系统均有参考价值。
5. **仿真-真实双线验证策略**：先在可控仿真中证明"异质性DAG vs 单一DAG"的优劣，再在真实医院数据上验证LLM与专家的一致性，为方法论论文提供了稳健的验证范式。

## 关键术语表
- **g-computation（g计算）**：由Robins (1986) 提出的因果效应估计方法，通过对因果图进行do-operator下的因子分解来模拟反事实分布，是本文方法的核心统计基础。
- **Egg-computation（专家引导的g计算）**：本文提出的新方法，将g-computation扩展至甘特图/时间顺序过程，结合专家/LLM推理与统计建模进行反事实模拟。
- **Waiting time（等待时间）**：事件 $k$ 从其所有父事件均已完成到其自身开始的时间间隔 $W_k$，是本文因果模型的基本变量。
- **Type I/II/III 节点**：根据节点与干预节点A的DAG位置关系分类——Type I为干预的非后代（直接复制事实时间），Type II为干预的后代但非直接子节点（用统计模型预测），Type III为干预的直接子节点（从专家分布采样）。
- **Disjunctive criterion（析取准则）**：混杂因素选择原则——一个变量只要是一个暴露变量的原因或是一个结局变量的原因，即应纳入因果图，本文以此指导LLM的节点扩展。
- **Average Time Saved（平均节省时间）**：本文估计的目标因果效应 $\tau = \mathbb{E}[Y(0) - Y(1)]$，表示干预政策相比现状平均能为每位患者节省的住院时长。
- **In-context learning（ICL，上下文学习）**：通过在prompt中提供若干few-shot示例，利用LLM自身知识进行预测，无需微调；本文用于Type II节点的等待时间预测。
- **Local Markov property（局部马尔可夫性质）**：在本模型的语境下指每个事件的等待时间仅取决于其父事件的时间，与给定父事件时间独立于非后代的墙壁时间。

- **代码/权重**：论文声明完整prompt模板将发布在配套的开源软件包中（"all prompts will be available in an open-source software package"），但未提供具体仓库链接；未提及预训练模型权重。
- **关键超参**：LLM使用GPT-5-mini（DAG构建）和GPT-5（时序预测/ICL）；ICL使用15个训练示例；DAG平均规模约14节点/21边；目标粒度为因果链路跨度不超过24小时；每诊断组/干预最多30例；bootstrap重采样2,000次。
