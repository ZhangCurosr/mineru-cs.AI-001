# 论文速读：On Understanding, Identifying, and Mitigating Vulnerabilities in Agentic Large Language Models

## 一句话总结
本文是基于 PRISMA 2020 指南的首个针对 Agentic LLM 安全漏洞的系统文献综述，筛选 85 篇论文（2023–2025），提出基于四架构层（感知层、大脑层、行动层、交互层）的 13 种漏洞分类体系，并揭示了攻击研究与防御研究 3.9:1 的严重失衡及感知层与行动层研究覆盖 14 倍差距等关键结构性缺口。

## 研究问题与动机
- **Agentic LLM 的安全威胁与传统 LLM 存在本质差异**：传统 LLM 安全研究聚焦于被动对话场景（prompt injection、jailbreaking、数据泄露），而 Agentic LLM 具备自主规划、工具调用、代码执行和持久记忆能力，一旦推理步骤被攻陷可引发级联失效、不可逆状态变更等全新风险。
- **现有安全防御方法与 Agentic LLM 架构演进脱节**：既有防御手段多沿用于传统 LLM 时代，未针对 Agent 的多层架构（感知→推理→执行→交互）设计分层隔离与检测机制，存在显著能力鸿沟。
- **缺乏系统性的漏洞分类与量化分析**：现有综述多为叙事型，未遵循系统文献回顾方法，也未提供基于 Agent 架构的漏洞分层分类，难以支撑定向安全设计。
- **攻击研究严重压倒防御研究**：文献中攻击类论文数量是防御/缓解类的 3.9 倍，且高后果的风险层（行动层）研究覆盖率仅 4.7%，与安全实践需求严重错配。

## 核心贡献（创新点）
- **首个 PRISMA 2020 合规的 Agentic LLM 安全系统综述**：从 743 条记录中筛选 85 篇同行评审论文（2023–2025），Cohen's κ 达 0.88/0.93，区别于此前未报告检索策略与评审者一致性的叙事综述。
- **提出基于 Agent 架构的四层漏洞分类体系**：将 13 种漏洞类型映射到感知层（Perception）、大脑层（Brain）、行动层（Action）和交互层（Interaction），以组件而非攻击名称为核心组织原则，为各层设计者提供可直接对应的安全指引。
- **首次量化揭示研究领域的结构性失衡**：攻击:防御 = 3.9:1；感知层研究占比 65.9% vs 行动层仅 4.7%（14 倍差距）；代码执行安全仅占 3.5%、具身 Agent 安全 0 篇，这些差距通过量化分析才被凸显。
- **识别七个关键开放问题与研究议程**：涵盖代码执行 Agent 安全、具身 Agent 安全、单 Agent 系统安全、检测成熟度、工具增强 Agent 覆盖、现实部署和标准化评估，提供短/中/长期研究方向。
- **构建统一的 Agentic LLM 安全栈框架**：整合漏洞分类、检测方法（输入级、运行时、多 Agent、形式化验证）和缓解策略（过滤、架构防御、运行时控制、训练时缓解、治理、多 Agent 防御），并给出各策略间的权衡对比表。

## 方法详解
- **系统文献回顾方法（PRISMA 2020）**：在 IEEE Xplore、ACM Digital Library、arXiv、Scopus、Web of Science、Google Scholar 六库检索，布尔查询组合为 (Group 1) AND (Group 2) NOT (Group 3)，辅以滚雪球采样和顶级会议论文集审查；最终纳入 85 篇（2023–2025）。
- **四层级架构模型**：
  - **感知层（Perception Layer）**：负责接收和处理来自用户、外部系统和环境的输入；易受 prompt injection、jailbreaking、对抗性扰动攻击。
  - **大脑层（Brain Layer）**：执行推理、规划和决策，包含 LLM 推理模块、规划机制、记忆系统；易受后门攻击、推理操纵、目标劫持、记忆投毒。
  - **行动层（Action Layer）**：执行工具调用、API 请求、代码执行等动作；是最高风险层，易受工具操纵、函数劫持、代码注入、沙箱逃逸影响，可能造成不可逆的外部状态变更。
  - **交互层（Interaction Layer）**：管理 Agent 间通信、环境交互和共享内存；易受消息注入、Agent 冒充、知识库污染影响。
- **威胁模型分类**：白盒（攻击者掌握权重/架构/训练信息）、灰盒（部分信息如架构/日志）、黑盒（仅 API/UI 输入输出），估计各类漏洞的最低攻击者技能要求。
- **数据提取与编码方案**：提取标题、作者、年份、会议、Agent 类型、漏洞类别、架构层、威胁模型、贡献性质等维度；17% 样本（15 篇）由第二评审人独立编码，分类一致性 94%/98%。
- **质量评估四维量表**（0–5 分制）：威胁模型清晰度（均值 4.1）、实验严谨性（均值 3.8）、可复现性（均值 3.5）、现实适用性（均值 2.9）。
- **漏洞频率与严重度量化**：采用类似 CVSS v3.1 的定性严重度分级（Critical/High/Medium），统计各组件层面的漏洞出现频次（非论文数，单篇可贡献多类别）。

## 实验与结果
- **文献规模与分布**：共纳入 85 篇论文（2025 年 62 篇占 72.9%，2024 年 21 篇，2023 年 2 篇），攻击导向论文 47 篇（55.3%），防御导向论文 12 篇（14.1%），综述/框架类 26 篇（30.6%）。
- **攻击:防御比例**：3.9:1，反映领域严重失衡。
- **架构层覆盖分布**：
  - 感知层：56 篇（65.9%）
  - 大脑层：35 篇（41%）
  - 行动层：4 篇（4.7%）
  - 交互层：24 篇（28%）
  - **感知层与行动层相差 14 倍**
- **Agent 架构类型分布**：多 Agent 系统 39 篇（46%）、RAG-based 25 篇（29%）、工具增强 10 篇（12%）、Web Agent 4 篇（4.7%）、代码执行 3 篇（3.5%）、具身 Agent 0 篇。
- **漏洞类型覆盖频次**：Prompt Injection 相关 36 篇最多，对抗性样本 30 篇，Jailbreaking 16 篇，记忆投毒 3 篇，代码注入 3 篇，沙箱逃逸 2 篇。
- **关键严重漏洞（行动层）**：Tool Manipulation 出现 54 次（频次最高）、Memory Poisoning 41 次、Adversarial Perturbations 42 次、CoT Manipulation 21 次、Code Injection 13 次（Critical 级）、Sandbox Escape 8 次（Critical 级）。
- **基准数据集**：识别 8 个公开基准，包括 Agent Security Bench (ASB)、InjecAgent（1,054 测试用例）、AgentDojo（97 任务/629 注入）、AgentHarm（440 行为）、AdvWeb、GOAT、MAD-Spear、Mobile Agent Security Matrix。
- **检测方法的结构性局限**：大部分检测集中于感知层，依赖 LLM-as-judge 存在循环设计，多数评估仅在单轮/受控条件下进行，缺乏自适应对抗测试和形式化保证；行动层执行监控几乎无专门检测方法。
- **防御策略权衡**：输入/输出过滤（中等效果、高可扩展、低开销）、架构防御（高效果、中等可扩展）、运行时控制（高效果、高开销/延迟）、训练时缓解（中等效果、低运行时开销）、人类治理（极高效果、低可扩展、高人类成本）、多 Agent 防御（中-高效果、中高开销）。

## 局限性与未来方向
- **时间窗口局限**：仅覆盖 2023 年 1 月至 2025 年 12 月，2025 年 Q4 后及之后的发表可能未被充分收录，需要"活体综述"持续更新。
- **语言偏差**：主要检索英文文献，非英文研究可能被遗漏。
- **发表偏差**：阳性结果更易发表，可能导致对防御/检测方法有效性的过度估计。
- **仅 85 篇论文**：反映 Agentic LLM 安全作为新兴子领域的早期阶段，随领域发展需持续扩展。
- **未来短期方向（1–2 年）**：代码执行 Agent 安全和工具增强 Agent 安全的紧迫研究；开发现实部署场景的实证研究。
- **未来中期方向（3–5 年）**：扩展至具身 Agent、形式化检测方法和工具供应链安全。
- **未来长期方向（5+ 年）**：安全属性的形式化验证、可信赖 Agent 架构、人类监督机制。
- **标准化需求**：统一漏洞分类、标准化评估指标、统一基准协议、负责任的漏洞披露指南。

## 研究启发与可借鉴点
- **四层架构分类法可直接迁移**：将感知→大脑→行动→交互的分层框架应用于本团队的 Agent 安全研究，可系统性地识别各层薄弱点和跨层传播路径。
- **量化缺口分析方法可复用**：通过统计各层/各类型的论文分布来发现研究盲区（如 14 倍感知层vs行动层差距），为本团队选择高价值研究方向提供数据支撑。
- **基准数据集清单具有参考价值**：本文汇总的 8 个公开基准（ASB、InjecAgent、AgentDojo、AgentHarm 等）可作为后续实验的评测基线。
- **"LLM-as-judge"循环性问题的警示**：当前检测研究大量依赖辅助 LLM 做判断，存在循环推理缺陷，可启发设计非 LLM 依赖的客观检测指标（如基于执行监控的硬约束验证）。
- **行动层安全的高优先级机会**：代码执行安全（仅 3.5% 研究覆盖）和沙箱逃逸（Critical 级）是严重研究空白，结合本团队在代码生成/执行方向的积累，可切入高影响力的研究赛道。

## 关键术语表
- **Agentic LLM**：以 LLM 为核心推理单元，具备自主感知、多步规划、工具调用、代码执行和持久记忆的 AI 系统。
- **Perception Layer（感知层）**：Agent 架构中负责接收和处理来自用户、环境和外部系统输入的组件层。
- **Brain Layer（大脑层）**：Agent 架构中负责推理、规划、决策和记忆管理的认知核心层。
- **Action Layer（行动层）**：Agent 架构中负责执行工具调用、API 请求、代码运行等对外动作的高风险层。
- **Interaction Layer（交互层）**：Agent 架构中管理 Agent 间通信、环境交互和共享状态的层。
- **Prompt Injection（Prompt 注入）**：攻击者通过直接（Direct）或间接（Indirect）方式在输入中嵌入恶意指令，绕过 Agent 原始意图的攻击。
- **Jailbreaking（越狱攻击）**：精心构造的提示词利用模型的模式复制倾向绕过安全护栏的攻击方式。
- **Sandbox Escape（沙箱逃逸）**：攻击者利用容器/沙箱配置缺陷或解释器能力，使恶意代码突破隔离访问宿主机资源的攻击。
- **Adaptive Adversarial Testing（自适应对抗测试）**：攻击者根据检测系统的反馈迭代优化攻击提示的评测方法，目前在该领域极少应用。
- **Agent Security Bench (ASB)**：2024 年提出的公开基准，用于形式化评测 LLM-based Agent 中的攻击与防御。
