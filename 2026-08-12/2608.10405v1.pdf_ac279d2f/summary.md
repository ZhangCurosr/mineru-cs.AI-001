# 论文速读：Never Stop Speaking: a Denial-of-Service Attack on End-to-End Speech Language Models

## 一句话总结
本文首次针对端到端语音大模型（E2E ALLMs）提出了一种基于扰动的拒绝服务（DoS）攻击方法，通过优化不可感知的声学扰动，联合抑制 EOS 生成概率与引导延长解码，迫使模型生成超长无意义静音片段，从而造成大量 GPU 计算资源消耗，并在 OpenSLR、QCRI 等数据集上验证了对 LFM2.5-Audio、FunAudioChat、Qwen2-Audio 等主流 E2E 语音模型的有效攻击。

## 研究问题与动机
- **核心问题**：端到端音频大语言模型（E2E ALLMs）的 DoS 安全漏洞尚未被系统探索，现有文本 LLM 的 DoS 攻击无法直接迁移至连续波形输入。
- **现有方法不足**：
  - 文本型 DoS 攻击（对抗后缀、语义诱导等）依赖离散 token 操作，不适用于连续音频模态；将文本查询直接转为语音输入后攻击效果有限。
  - 针对 ASR 模型的 DoS 攻击仅优化 EOS logit，缺乏对解码长度、语义一致性和生成稳定性的联合约束，易导致提前终止失败。
  - 已有音频模型攻击方法损失函数过于简单，未充分利用多目标联合优化，攻击成功率（ASR）和输出延长效果不佳。
  - 在无声段添加扰动会引入可听见的失真，影响隐蔽性；需要仅在语音活动区添加扰动以提升隐蔽性。

## 核心贡献（创新点）
- **首次提出面向 E2E ALLMs 的端到端 DoS 攻击框架**：与 ASR 单一组件攻击或文本 LLM 攻击的本质区别在于直接作用于连续音频波形并联合控制自回归解码全过程，填补了 E2E 语音大模型安全研究的空白。
- **设计四分量复合损失函数实现精细化的多目标优化**：通过加权 EOS loss（引入符号门控与指数动态增长权重）、length loss（基于 EOS 概率分布的期望长度逼近）、top-k logit loss（间接抑制 EOS 并维持语音连贯性）和语义对齐 loss（保障输入语义一致性）的联合优化，区别于仅依赖单一 EOS 抑制的传统方法。
- **引入 VAD（语音活动检测）策略实现扰动区域的精准投放**：仅在有声段添加扰动、无声段保持原样，在提升攻击隐蔽性的同时不削弱攻击效果，相比全局噪声注入具有更优的隐蔽—效果权衡。
- **系统性实验验证 + 多维度分析**：在三个开源 E2E ALLM 上全面评估 ASR、输出长度、GPU 显存占用及响应质量，并开展消融实验、解码策略鲁棒性、跨模型可迁移性及压缩鲁棒性分析，揭示了 E2E ALLMs 在自回归生成控制方面的固有脆弱性。

## 方法详解
- **威胁模型**：白盒攻击设置，攻击者拥有目标模型完整架构与参数访问权限，可对输入语音计算梯度；仅引入低于人耳感知阈值的微小不可感知扰动，不修改模型或部署环境。
- **优化形式化**：将初始音频 $\mathbf{X}$ 通过 VAD 分割为有声段 $V = \{x_1, x_2, \ldots, x_n\}$ 与无声段 $S = \{y_1, y_2, \ldots, y_n\}$，对每个有声段优化扰动 $\sigma_i$，使 $\hat{x} = Concat(\{x_i + \sigma_i\}, S)$ 经目标模型 F 后产生尽可能长的输出。约束条件为 $\|\sigma_i\|_\infty \leq \epsilon = 10^{-4}$，使用 PGD 迭代优化 200 步。
- **复合损失函数** $\mathcal{L}_{DoS} = \mathcal{L}_{eos} + \mathcal{L}_{topk} + \mathcal{L}_{len} + \mathcal{L}_{sem}$：
  - **$\mathcal{L}_{eos}$（加权 EOS logit 损失）**：$\mathcal{L}_{eos} = \frac{1}{N}\sum_{t=1}^{N} w_t \ell_{EOS,t}$，其中 $w_t = w_{high}\exp(\frac{t}{N}\kappa)$（当 $\ell_{EOS,t}>0$ 时生效，否则为 0），$w_{high}=4$、$\kappa=4$，对后期自回归步赋予更大权重以重点压制逐步增强的 EOS 概率。
  - **$\mathcal{L}_{len}$（长度损失）**：基于每步 EOS 概率 $p_t = \sigma(z_t)$ 计算期望生成长度 $\mathbb{E}[L] = \sum_{t=1}^{N} t(p_t \prod_{i=1}^{t-1}(1-p_i))$，定义 $\mathcal{L}_{len} = \frac{(N_{max} - \mathbb{E}[L])^2}{N_{max}}$，引导输出逼近最大 token 数 $N_{max}=1024$。
  - **$\mathcal{L}_{topk}$（top-k logit 损失）**：$\mathcal{L}_{topk} = -\frac{1}{N}\sum_{t=1}^{N}\frac{1}{K}\sum_{k=1}^{K}\ell_{topk,t}^{(k)}$，$K=3$，通过提升 top-k  token 概率间接压低 EOS 概率，同时保持合成语音连贯性。
  - **$\mathcal{L}_{sem}$（语义对齐损失）**：$\mathcal{L}_{sem} = 1 - \frac{\langle s(x), s(x+\delta)\rangle}{\|s(x)\|_2\|s(x+\delta)\|_2}$，使用语音编码器提取特征并计算余弦相似度，确保原始音频与对抗音频语义一致，避免输出长度变化归因于语义改变。
- **优化流程**：每轮迭代将随机高斯初始化的有声段扰动与未修改无声段拼接重构完整对抗波形，经语音编码器提取声学特征后送入自回归解码器，记录每步 EOS logit、top-k logit 和总生成长度，计算 $\mathcal{L}_{DoS}$ 后经反向传播和 PGD 更新扰动，直至输出达到 $N_{max}$ 或迭代次数耗尽。

## 实验与结果
- **数据集**：OpenSLR 和 QCRI 两个公开语音数据集，各随机采样 100 个干净音频样本进行评估。
- **评估模型**：LFM2.5-Audio-1.5B、FunAudioChat-8B、Qwen2-Audio-7B-Instruct 三个开源 E2E ALLM。
- **评估基线**：干净音频、随机噪声、仅 EOS 朴素损失（Simple Loss）、Crabs（文本 LLM DoS 攻击）、ExtendAttack（LRM DoS 攻击）、全局噪声注入（无 VAD）变体。
- **评估指标**：攻击成功率（ASR）、平均输出 token 长度、峰值 GPU 显存占用、响应质量（LLM-as-judge 1-5 分）。
- **主要结果**：
  - 在 LFM2.5-Audio 上，本文方法 ASR 达 87%（Simple Loss 为 79%），平均输出长度 941.88 tokens（约为干净输入的 4.7 倍），GPU 显存从 8.89 GB 升至 10.78 GB。
  - 在 FunAudioChat 上，ASR 达 84%，平均输出长度 920.24 tokens，显存从 20.26 GB 升至 21.93 GB。
  - 在 Qwen2-Audio 上，ASR 达 83%，平均输出长度 913.07 tokens，显存从 18.42 GB 升至 19.94 GB。
  - 文本型攻击 Crabs 和 ExtendAttack 迁移至音频领域效果极差（ASR 分别仅 0.34–0.48），验证了离散 token 策略在连续音频上的无效性。
- **最强结果**：LFM2.5-Audio 上 ASR 87%、输出长度 941.88 tokens；相较 Simple Loss 基线，ASR 提升约 8 个百分点，输出长度提升约 9.7%。

## 相关工作脉络
- **文本 LLM DoS 攻击（Crabs、ExtendAttack 等）**：基于对抗后缀或复杂语义查询构建攻击树/细分推理步骤，依赖离散 token 编辑；本文指出此类策略无法直接迁移到连续音频模态，并通过实验验证了其低迁移性（ASR 仅 34%–48%）。
- **ASR 模型 DoS 攻击（SlothSpeech）**：仅针对语音识别模型的 EOS logit 进行朴素抑制，无法应对 E2E ALLM 中复杂的端到端生成过程；本文通过四分量联合损失克服了单一 EOS 优化的局限。
- **文本 LLM DoS 新方法（NaturalSloth、Reasoning-Bomb）**：针对 LLM 推理瓶颈和过度推理路径的攻击，核心仍围绕文本 token 序列操纵；本文转向连续音频扰动空间，提出全新的优化范式。
- **E2E ALLM 架构研究（Ichigo、LFM2.5、Qwen2-Audio 等）**：这些模型采用文本-语音对齐策略实现双向理解与生成；本文揭示其共同依赖的自回归解码机制存在被扰动 exploited 的通用漏洞。
- **VAD 在对抗攻击中的应用（Ko, Kim, Kwon 2026）**：先前工作仅利用 VAD 避免无声段噪声引入可听伪影；本文进一步将其作为提升攻击隐蔽性与语义一致性的关键组件，与多损失函数协同工作。
- **音频对抗攻击（传统方法）**：以往音频模型对抗攻击多使用简单损失函数，攻击性能不佳；本文通过精密的多目标优化与 VAD 引导的区域化扰动显著提升了攻击有效性和隐蔽性。

## 局限性与未来方向
- **有损压缩削弱攻击有效性**：MP3 等音频压缩算法会量化/消除细粒度声学细节，破坏优化后的扰动模式；重采样、滤波、噪声注入等信号级变换同样会降低攻击鲁棒性。
- **白盒假设限制实际部署**：当前方法依赖模型参数与梯度可访问性，在黑盒场景下仅表现出 7%–13% 的跨模型迁移率，实际应用范围受限。
- **防御机制尚不成熟**：现有信号级预处理（压缩、滤波等）虽能削弱攻击但引入额外延迟和音质退化；自适应攻击者可针对预处理流程优化扰动，削弱此类防御效果。
- **未来方向**：开发低延迟、高音质保真的实用防御机制以有效干扰音频域对抗扰动；探索黑盒场景下更强的跨模型迁移策略；将攻击框架扩展至多模态大模型的安全评估。

## 研究启发与可借鉴点
- **多目标联合优化范式可迁移**：本文的加权 EOS loss（符号门控 + 指数动态权重）设计思路可用于其他序列生成模型（如文本 LRM）的 DoS 攻击研究，实现对早期/晚期生成步骤的差异化压制。
- **VAD 引导的扰动区域选择策略**：仅在信息丰富的语音活动段添加扰动、屏蔽无声段的思路可推广至其他音频处理任务（如说话人验证、情感识别）的对抗攻击与防御设计。
- **期望长度可微分估计技巧**：基于每步终止概率推导期望生成长度的公式（式 6）为离散输出长度优化提供了可微分替代方案，可借鉴于任何自回归生成模型的长度控制研究。
- **LLM-as-judge 评估响应质量**：使用 ChatGPT 等 LLM 对生成结果进行语义一致性与质量打分（1-5 分）的自动化评估方法，可作为后续语音模型安全研究的标准评估流程。
- **跨模型可迁移性分析框架**：本文的跨模型攻击迁移实验设计（白盒→黑盒迁移率矩阵）可直接复用于评估其他新型多模态模型的对抗鲁棒性。

## 关键术语表
**E2E ALLM（端到端音频大语言模型）**：无需显式中间转写表示、直接处理连续音频波形并进行双向语音-文本理解与生成的 Transformer 架构大模型。
**DoS（拒绝服务攻击）**：通过构造特殊输入迫使模型生成过长输出，耗尽服务器计算资源、导致合法请求无法得到响应的安全攻击类型。
**EOS（End-of-Sentence token）**：标记生成序列结束的专用 token，抑制其概率可有效延长模型输出长度。
**PGD（投影梯度下降）**：一种迭代优化算法，在每步梯度更新后将扰动投影回约束范数范围内，广泛用于对抗样本生成。
**VAD（语音活动检测）**：区分音频中有声段与静音/背景噪声段的技术，本文用于指导扰动仅注入含信息的语音活动区域以提升隐蔽性。
**ASR（Attack Success Rate，攻击成功率）**：攻击样本中成功迫使目标模型输出达到最大 token 数限制的样本占比。
**Top-k sampling**：每步从概率最高的 k 个 token 中采样输出的解码策略；本文同时将其 logits 纳入损失优化以实现间接 EOS 抑制。
**LLM-as-judge**：利用大语言模型作为自动评估器，对生成文本进行质量打分和语义一致性判断的评估范式。
